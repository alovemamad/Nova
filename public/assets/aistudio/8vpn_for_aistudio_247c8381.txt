# 8 VPN — English

A lightweight Android VPN client built on the **Aether** core, with **sing-box** (libbox) as the default TUN engine and **hev-socks5-tunnel** as the fallback.
Jetpack Compose, Material 3, dark by default, English and Persian (RTL).

📢 Telegram channel: <https://t.me/Clubapp8>

## Features

- **Two modes**: VPN (the whole device goes through the tunnel) or Proxy-only (a local SOCKS5 and optional HTTP proxy). The VPN / Proxy choice and the route switcher live in **Settings**, so the home screen stays clean.
- **Route switcher**: Aether, Aether → Psiphon, Aether → Tor, Psiphon only, Tor only, and the reverse routes (Psiphon → MASQUE, Tor → MASQUE).
  Aether protocols: MASQUE, WireGuard, WARP-in-MASQUE (Gool), WARP-in-WARP (Gool classic) and MASQUE-in-MASQUE. Psiphon has region and mode selection, Tor has bridge options including **custom bridges** (obfs4 and webtunnel lines in a fixed-size scrollable box, with a button to get bridges from the Telegram bot @GetBridgesBot and paste them).
- **Smart reconnect**: reconnects when the core dies, when pings fail, or when the network changes (Wi-Fi ↔ mobile data). It retries with a fresh gateway scan, or goes back quickly to the last working gateway.
- **Custom endpoint**: set your own gateway `IP:port` (outer and inner hop) and skip the scan.
- **Share the proxy with other devices**: let a laptop or another phone use the SOCKS5 / HTTP proxy through your hotspot or USB tethering. The *Share SOCKS5 and HTTP* section lists every address you can connect to in one box (tap to copy), with separate switches for HTTP on this phone and for other devices.
- **One address for everything**: *Share everything on one address* gives SOCKS5 and HTTP on a single port (default `1830`) that always carries the **final output** of the connected mode (Aether, Aether → Psiphon, Aether → Tor, Psiphon only or Tor only).
- **Split tunneling**: include only selected apps or exclude them.
- **Routing rules**: block list and direct list (domains, IPs, CIDR, ports), custom DNS inside the tunnel, upstream proxy (`socks5://` or `http://`).
- **Pause and resume**: the Stop button turns the VPN off while the core keeps running, so Start resumes at once.
- **Tuning**: scan level, obfuscation profile, IP version, performance profile, TUN MTU, TCP buffer, ping interval and failure count, connection attempts and delay, extra Aether arguments.
- **Live info**: ping, download/upload speed, link speed, exit IP with country flag, the reason of the last drop, and logs you can copy or share.
- **Update check**: checks the latest GitHub release from the About screen. It never downloads or installs anything by itself.
- **Collapsible settings**: General, Split tunneling, Core and protocol, Routing, Psiphon, Tor, Share SOCKS5 and HTTP, Advanced and Clear cache are separate sections, and a logs button sits at the top of Settings.
- Quick Settings tile (toggle the VPN from the status bar), start on boot, battery-optimization shortcut, dynamic color (Android 12+), dark / light theme.
- English and Persian UI with full RTL support.

## How it works

```
VPN mode:    apps -> VpnService (TUN) -> sing-box (gVisor stack) -> SOCKS5 127.0.0.1:1819 -> Aether / Psiphon / Tor -> internet
Proxy-only:  apps -> SOCKS5 127.0.0.1:1819 (or HTTP 127.0.0.1:1822) -> Aether / Psiphon / Tor -> internet
```

Ports: SOCKS5 `1819` (configurable), Tor `1820`, Psiphon `1821`, optional HTTP `1822` (configurable), shared single address `1830` (configurable, listens on `0.0.0.0` by default).

**TUN engines** (Settings → VPN engine):

- **sing-box** (default): DNS is answered by sing-box (DNS over TCP through the proxy). For Psiphon and Tor, non-DNS UDP is refused at once, so apps fall back from QUIC to TCP.
- **hev-socks5-tunnel**: the lightweight alternative. The app falls back to it automatically if the sing-box library is missing or fails to start.

## Notes

- Aether is AGPL-3.0, so this project is AGPL-3.0 too (see [LICENSE](LICENSE)).
- Aether's trademark policy asks derivative products to use their own name and branding, so the app is named **8 VPN** and the core is only credited.
- The Psiphon region list is static; the real set depends on Psiphon's servers.
- Custom Tor bridges only support obfs4, webtunnel and plain bridges; other transports are skipped.
- Sharing the proxy lets anyone on the same hotspot or Wi-Fi network use it. Use a strong hotspot password and turn sharing off when you are done.

# 8VPN — فارسی

یک کلاینت سبک VPN برای اندروید، ساخته‌شده روی هسته‌ی **Aether**، با **sing-box** (کتابخانه‌ی libbox) به‌عنوان موتور پیش‌فرض TUN و **hev-socks5-tunnel** به‌عنوان جایگزین.
با Jetpack Compose و Material 3، پیش‌فرض تیره، با رابط فارسی (راست‌به‌چپ) و انگلیسی.

📢 کانال تلگرام: <https://t.me/Clubapp8>

## امکانات

- **دو حالت**: VPN (کل دستگاه از تونل رد می‌شود) یا فقط پروکسی (یک SOCKS5 محلی و در صورت نیاز پروکسی HTTP). انتخاب حالت VPN / پروکسی و مسیر در **تنظیمات** است تا صفحه‌ی اصلی ساده بماند.
- **انتخاب مسیر**: Aether، Aether ← Psiphon، Aether ← Tor، فقط Psiphon، فقط Tor و مسیرهای معکوس (Psiphon ← MASQUE و Tor ← MASQUE).
  پروتکل‌های Aether: MASQUE، WireGuard، WARP-in-MASQUE (Gool)، WARP-in-WARP (Gool classic) و MASQUE-in-MASQUE. برای Psiphon انتخاب منطقه و حالت و برای Tor گزینه‌های بریج هست، از جمله **بریج دلخواه** (خط‌های obfs4 و webtunnel در یک کادر اسکرول‌شونده با اندازه‌ی ثابت، و دکمه‌ای برای گرفتن بریج از ربات تلگرام @GetBridgesBot و چسباندن آن).
- **اتصال مجدد هوشمند**: اگر هسته از کار بیفتد، پینگ‌ها شکست بخورند یا شبکه عوض شود (وای‌فای ↔ دیتای موبایل) دوباره وصل می‌شود؛ یا با اسکن تازه‌ی گیت‌وی تلاش می‌کند یا سریع به آخرین گیت‌وی سالم برمی‌گردد.
- **اندپوینت دلخواه**: گیت‌وی خودتان را به‌صورت `IP:port` (پرش بیرونی و داخلی) بدهید تا اسکن انجام نشود.
- **اشتراک‌گذاری پروکسی با دستگاه‌های دیگر**: از طریق هات‌اسپات یا USB tethering، لپ‌تاپ یا گوشی دیگر می‌تواند از SOCKS5 / HTTP گوشی استفاده کند. بخش *اشتراک SOCKS5 و HTTP* همه‌ی آدرس‌های قابل اتصال را در یک کادر نشان می‌دهد (با لمس کپی می‌شود) و برای HTTP روی همین گوشی و روی دستگاه‌های دیگر کلید جداگانه دارد.
- **یک آدرس برای همه‌چیز**: گزینه‌ی *اشتراک همه‌چیز روی یک آدرس* یک پورت واحد (پیش‌فرض `1830`) برای SOCKS5 و HTTP می‌دهد که همیشه **خروجی نهایی** حالت متصل‌شده را شیر می‌کند (Aether، Aether ← Psiphon، Aether ← Tor، فقط Psiphon یا فقط Tor).
- **تونل‌سازی انتخابی (Split tunneling)**: فقط برنامه‌های انتخاب‌شده یا همه به‌جز آن‌ها.
- **قوانین مسیریابی**: فهرست بلاک و فهرست مستقیم (دامنه، IP، CIDR، پورت)، DNS دلخواه داخل تونل و پروکسی بالادستی (`socks5://` یا `http://`).
- **توقف و ادامه**: دکمه‌ی Stop فقط VPN را خاموش می‌کند و هسته روشن می‌ماند، پس Start فوری ادامه می‌دهد.
- **تنظیمات دقیق**: سطح اسکن، پروفایل مبهم‌سازی، نسخه‌ی IP، پروفایل کارایی، MTU و بافر TCP، فاصله و تعداد خطای پینگ، تعداد و فاصله‌ی تلاش‌های اتصال و آرگومان‌های اضافه‌ی Aether.
- **اطلاعات زنده**: پینگ، سرعت دانلود و آپلود، سرعت لینک، IP خروجی همراه با پرچم کشور، دلیل آخرین قطع شدن و لاگ‌هایی که می‌توانید کپی یا ارسال کنید.
- **بررسی آپدیت**: از صفحه‌ی About آخرین ریلیز گیت‌هاب را چک می‌کند و خودش چیزی دانلود یا نصب نمی‌کند.
- **تنظیمات تاشو**: General، Split tunneling، Core and protocol، Routing، Psiphon، Tor، اشتراک SOCKS5 و HTTP، Advanced و Clear cache هرکدام بخش جداگانه دارند و دکمه‌ی لاگ‌ها بالای تنظیمات است.
- کاشی تنظیمات سریع (وصل و قطع VPN از نوار اعلان‌ها)، اجرا هنگام بوت، میان‌بر مجوز باتری، رنگ پویا (اندروید ۱۲+)، تم تیره و روشن.
- رابط فارسی و انگلیسی با پشتیبانی کامل از راست‌به‌چپ.

پورت‌ها: SOCKS5 روی `1819` (قابل تغییر)، Tor روی `1820`، Psiphon روی `1821` و HTTP اختیاری روی `1822` (قابل تغییر) و آدرس واحد اشتراکی روی `1830` (قابل تغییر؛ پیش‌فرض روی `0.0.0.0` گوش می‌دهد).

**موتورهای TUN** (تنظیمات ← موتور VPN):

- **sing-box** (پیش‌فرض): DNS را خود sing-box جواب می‌دهد (DNS روی TCP از طریق پروکسی). برای Psiphon و Tor، UDP غیر از DNS فوراً رد می‌شود تا برنامه‌ها از QUIC به TCP برگردند.
- **hev-socks5-tunnel**: جایگزین سبک. اگر کتابخانه‌ی sing-box نباشد یا اجرا نشود، برنامه خودکار به آن برمی‌گردد.

===== FILE: .github/workflows/main.yml =====
name: Build APKs

on:
  push:
    branches: [main, master]
    tags: ["v*"]
  workflow_dispatch:
    inputs:
      aether_repo:
        description: "Aether repository (use your own fork if you changed the core)"
        default: "CluvexStudio/Aether"
      aether_ref:
        description: "Aether tag, branch or full commit hash"
        default: "v2.4.0"
      singbox_ref:
        description: "sing-box tag (the libbox library is built from it)"
        default: "v1.13.21"

permissions:
  contents: write

env:
  # Upstream refs. Change them here if you want other versions.
  AETHER_REPO: ${{ inputs.aether_repo || 'CluvexStudio/Aether' }}
  AETHER_REF: ${{ inputs.aether_ref || 'v2.4.0' }}
  HEV_REF: 2.19.0
  SINGBOX_REF: ${{ inputs.singbox_ref || 'v1.13.21' }}

jobs:
  native:
    name: Native libs (${{ matrix.abi }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: true
      matrix:
        include:
          - { abi: arm64-v8a,   target: aarch64-linux-android,   goarch: arm64, goarm: "" }
          - { abi: armeabi-v7a, target: armv7-linux-androideabi, goarch: arm,   goarm: "7" }
          - { abi: x86_64,      target: x86_64-linux-android,    goarch: amd64, goarm: "" }
    steps:
      - name: Checkout (this repo)
        uses: actions/checkout@v4

      - name: Checkout Aether
        uses: actions/checkout@v4
        with:
          repository: ${{ env.AETHER_REPO }}
          ref: ${{ env.AETHER_REF }}
          path: aether-src
          persist-credentials: false

      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.target }}

      - uses: actions/setup-go@v5
        with:
          go-version: "1.22"

      - uses: lukka/get-cmake@latest

      - name: Install Android NDK
        id: ndk
        uses: nttld/setup-ndk@v1
        with:
          ndk-version: r26d

      - name: Install cargo-ndk
        run: cargo install cargo-ndk --locked

      - name: Build Psiphon and Lyrebird (Go)
        run: |
          out="$GITHUB_WORKSPACE/stage/pt"
          mkdir -p "$out"
          bash aether-src/pt-build.sh linux ${{ matrix.goarch }} "$out" "${{ matrix.goarm }}"
          bash aether-src/psiphon-build.sh linux ${{ matrix.goarch }} "$out" "${{ matrix.goarm }}"
          ls -l "$out"

      - name: Build Aether (Rust, with Tor)
        working-directory: aether-src/aether
        env:
          ANDROID_NDK_HOME: ${{ steps.ndk.outputs.ndk-path }}
          ANDROID_NDK_ROOT: ${{ steps.ndk.outputs.ndk-path }}
        run: |
          under=$(echo "${{ matrix.target }}" | tr '-' '_')
          export "BORING_BSSL_RUST_CPPLIB_${under}=static:-bundle=c++"
          cargo ndk -t ${{ matrix.abi }} --platform 26 build --release --features tor
          bin="target/${{ matrix.target }}/release/aether"
          needed=$(readelf -d "$bin" | sed -n 's/.*(NEEDED).*\[\(.*\)\]/\1/p')
          echo "aether NEEDED: $needed"
          if grep -qx 'libc++_shared.so' <<<"$needed"; then
            echo "ERROR: aether still needs libc++_shared.so"; exit 1
          fi

      - name: Build hev-socks5-tunnel (JNI library)
        env:
          ANDROID_NDK_HOME: ${{ steps.ndk.outputs.ndk-path }}
        run: |
          git clone --recursive --depth 1 --branch "$HEV_REF" https://github.com/heiher/hev-socks5-tunnel.git hev

package app.vpn8

import android.content.Context
import android.net.ConnectivityManager
import android.net.NetworkCapabilities
import java.io.File
import java.net.Inet4Address

/** Turns the user's settings into Aether command line flags. */
object ArgBuilder {
    fun exitPort(s: Settings): Int = when (s.route) {
        Route.AETHER_PSIPHON -> PSIPHON_PORT
        Route.AETHER_TOR -> TOR_PORT
        else -> s.socksPort
    }

    private fun csv(v: String) = v.split(',', '\n', ' ', ';').map { it.trim() }.filter { it.isNotEmpty() }.joinToString(",")

    fun build(ctx: Context, s: Settings, fresh: Boolean, psiSlot: Int = 0): List<String> {
        val dir = File(ctx.filesDir, "aether")
        val nl = ctx.applicationInfo.nativeLibraryDir
        val a = ArrayList<String>()
        val r = s.route

        a += listOf("--config", File(dir, "aether.toml").path)
        a += listOf("--bind", "${s.socksBind()}:${s.socksPort}")
        if (s.httpActive) a += listOf("--http-proxy", "${s.httpBind()}:${s.httpPort}")

        when (r) {
            Route.AETHER_PSIPHON -> a += "--psiphon"
            Route.PSIPHON_ONLY -> a += "--psiphon-only"
            Route.PSIPHON_REVERSE -> a += "--psiphon-reverse"
            Route.AETHER_TOR -> a += "--tor"
            Route.TOR_ONLY -> a += "--tor-only"
            Route.TOR_REVERSE -> a += "--tor-reverse"
            Route.AETHER -> {}
        }

        if (!r.noWarp) {
            // Reverse routes carry MASQUE over HTTP/2 only (Tor and Psiphon are TCP only).
            val proto = if (r.reverse) Protocol.MASQUE else s.protocol
            when (proto) {
                Protocol.MASQUE -> a += listOf("--protocol", "masque")
                Protocol.WIREGUARD -> a += listOf("--protocol", "wg")
                Protocol.GOOL -> a += listOf("--protocol", "gool")
                Protocol.GOOL_CLASSIC -> a += "--gool-classic"
                Protocol.MIM -> a += listOf("--protocol", "mim")
            }
            if (r.reverse) a += "--h2"
            else if (proto == Protocol.MASQUE || proto == Protocol.MIM) a += if (s.carrier == "h2") "--h2" else "--h3"

            // Custom gateway: naming a peer makes the core skip scanning. Invalid text is ignored.
            val ep = Endpoints.clean(s.endpoint)
            val ep2 = Endpoints.clean(s.endpoint2)
            val h2 = r.reverse || s.carrier == "h2"
            when (proto) {
                Protocol.MASQUE -> if (ep != null) {
                    a += listOf("--peer", ep)
                    if (h2) a += listOf("--h2-peer", ep)
                }
                Protocol.WIREGUARD -> if (ep != null) a += listOf("--peer", ep)
                Protocol.GOOL -> {
                    if (ep != null) a += listOf("--peer", ep)
                    if (ep2 != null) a += listOf("--gool-peer", ep2)
                }
                Protocol.GOOL_CLASSIC -> {
                    if (ep != null) a += listOf("--wiw-outer", ep)
                    if (ep2 != null) a += listOf("--wiw-inner", ep2)
                }
                Protocol.MIM -> {
                    if (ep != null) a += listOf("--mim-outer", ep)
                    if (ep2 != null) a += listOf("--mim-inner", ep2)
                }
            }

            a += listOf("--scan", s.scan)
            if (s.noize != "default") a += listOf("--noize", s.noize)
            a += when (s.ipVersion) { "6" -> "-6"; "dual" -> "--dual"; else -> "-4" }
            a += if (fresh || !s.quickReconnect) "--no-quick-reconnect" else "--quick-reconnect"
            if (s.dns.isNotBlank()) a += listOf("--dns", csv(s.dns))
        }

        if (s.routeBlock.isNotBlank()) a += listOf("--route-block", csv(s.routeBlock))
        if (s.routeDirect.isNotBlank()) a += listOf("--route-direct", csv(s.routeDirect))
        if (s.upstream.isNotBlank()) a += listOf("--upstream", s.upstream.trim())

        if (r.usesPsiphon) {
            a += listOf("--psiphon-bin", "$nl/libpsiphon.so")
            a += listOf("--psiphon-dir", File(dir, if (psiSlot == 0) "psiphon" else "psiphon-$psiSlot").path)
            if (r != Route.PSIPHON_ONLY) a += listOf("--psiphon-bind", "${s.socksBind()}:$PSIPHON_PORT")
            a += listOf("--psiphon-mode", s.psiphonMode)
            if (s.psiphonRegion.isNotBlank()) a += listOf("--psiphon-region", s.psiphonRegion.uppercase())
            // Psiphon (a Go program) finds no DNS server on Android and tries 127.0.0.1:53, which
            // is refused, so it can never download its server list. Give it real DNS servers.
            // A --psiphon-config the user typed in the extra arguments wins.
            if (!s.extraArgs.contains("--psiphon-config")) {
                psiphonConfig(ctx, s, dir)?.let { a += listOf("--psiphon-config", it.path) }
            }
        }
        if (r.usesTor) {
            a += listOf("--tor-dir", File(dir, "tor").path)
            if (r != Route.TOR_ONLY) a += listOf("--tor-bind", "${s.socksBind()}:$TOR_PORT")
            when (s.torBridges) {
                "always" -> a += "--tor-bridges"
                "never" -> a += "--no-tor-bridges"
                "custom" -> {
                    // The user's own bridge lines go to a file in torrc shape; empty or unusable text means automatic.
                    val txt = TorBridges.fileText(s.torCustomBridges)
                    if (txt.isNotEmpty()) {
                        dir.mkdirs()
                        val f = File(dir, "tor-bridges.txt")
                        f.writeText(txt + "\n")
                        a += listOf("--tor-bridge-file", f.path)
                    }
                }
            }
        }
        if (s.perf != "auto") a += listOf("--perf", s.perf)
        a += splitArgs(s.extraArgs)
        return a
    }

    /**
     * Writes a small Psiphon config laid over Aether's built-in one. It only sets
     * DNSResolverAlternateServers: the phone's own DNS servers first (they work on this very
     * network), then the user's DNS setting, then a few public resolvers.
     */
    private fun psiphonConfig(ctx: Context, s: Settings, dir: File): File? = try {
        val servers = LinkedHashSet<String>()
        servers += systemDns(ctx)
        s.dns.split(',', ' ', ';', '\n').map { it.trim() }.filter { Hosts.valid(it) }.forEach { servers += it }
        servers += listOf("1.1.1.1", "8.8.8.8", "9.9.9.9", "1.0.0.1", "8.8.4.4")
        val list = servers.filter { it != "0.0.0.0" && !it.startsWith("127.") }.take(8)
        dir.mkdirs()
        val f = File(dir, "psiphon-config.json")
        f.writeText("{\"DNSResolverAlternateServers\":[" + list.joinToString(",") { "\"$it\"" } + "]}\n")
        Engine.log("Psiphon DNS servers: " + list.joinToString(", "))
        f
    } catch (e: Exception) {
        Engine.log("Could not write the Psiphon DNS config: ${e.message}")
        null
    }

    /** IPv4 DNS servers of the phone's real (non-VPN) networks, the active one first. */
    private fun systemDns(ctx: Context): List<String> = try {
        val cm = ctx.getSystemService(ConnectivityManager::class.java)
        val active = cm?.activeNetwork
        val nets = (cm?.allNetworks ?: emptyArray()).sortedByDescending { it == active }
        nets.filter { n ->
            cm?.getNetworkCapabilities(n)?.hasCapability(NetworkCapabilities.NET_CAPABILITY_NOT_VPN) == true
        }.flatMap { n ->
            cm?.getLinkProperties(n)?.dnsServers.orEmpty().filterIsInstance<Inet4Address>().mapNotNull { it.hostAddress }
        }.distinct()
    } catch (_: Exception) {
        emptyList()
    }

    /** Splits a command line the way a shell would for simple cases: spaces separate, quotes group. */
    fun splitArgs(v: String): List<String> {
        val out = ArrayList<String>()
        val sb = StringBuilder()
        var quote: Char? = null
        var has = false
        for (ch in v) {
            when {
                quote != null -> if (ch == quote) quote = null else sb.append(ch)
                ch == '"' || ch == '\'' -> { quote = ch; has = true }
                ch.isWhitespace() -> if (has || sb.isNotEmpty()) { out += sb.toString(); sb.clear(); has = false }
                else -> sb.append(ch)
            }
        }
        if (has || sb.isNotEmpty()) out += sb.toString()
        return out
    }
}

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.net.VpnService

class BootReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action != Intent.ACTION_BOOT_COMPLETED) return
        SettingsStore.init(context)
        val s = SettingsStore.current
        if (!s.autoStart) return
        if (s.vpnMode && VpnService.prepare(context) != null) return // permission not granted yet
        TunnelService.start(context)
    }
}

@Composable
fun Icon8(ico: Ico, tint: Color, sz: Dp = 22.dp, modifier: Modifier = Modifier, strokeW: Float = 2f) {
    val rtl = LocalLayoutDirection.current == LayoutDirection.Rtl
    Canvas(modifier.size(sz)) {
        val u = this.size.width / 24f
        val flip = rtl && (ico == Ico.BACK)
        fun p(x: Float, y: Float) = Offset((if (flip) 24f - x else x) * u, y * u)
        val st = Stroke(width = strokeW * u, cap = StrokeCap.Round, join = StrokeJoin.Round)
        fun line(x1: Float, y1: Float, x2: Float, y2: Float) =
            drawLine(tint, p(x1, y1), p(x2, y2), strokeWidth = strokeW * u, cap = StrokeCap.Round)
        fun poly(close: Boolean, vararg pts: Float) {
            val path = Path()
            path.moveTo(p(pts[0], pts[1]).x, p(pts[0], pts[1]).y)
            var i = 2
            while (i < pts.size) {
                path.lineTo(p(pts[i], pts[i + 1]).x, p(pts[i], pts[i + 1]).y)
                i += 2
            }
            if (close) path.close()
            drawPath(path, tint, style = st)
        }
        when (ico) {
            Ico.BACK -> { line(20f, 12f, 5f, 12f); poly(false, 11f, 6f, 5f, 12f, 11f, 18f) }
            Ico.SETTINGS -> {
                line(4f, 7f, 20f, 7f); line(4f, 12f, 20f, 12f); line(4f, 17f, 20f, 17f)
                drawCircle(tint, radius = 2.6f * u, center = p(9f, 7f))
                drawCircle(tint, radius = 2.6f * u, center = p(15f, 12f))
                drawCircle(tint, radius = 2.6f * u, center = p(8f, 17f))
            }
            Ico.LOGS -> {

            Ico.POWER -> {
                drawArc(tint, startAngle = -55f, sweepAngle = 290f, useCenter = false, topLeft = p(4.5f, 5.5f), size = Size(15f * u, 15f * u), style = st)
                line(12f, 3f, 12f, 12f)
            }
            Ico.CHECK -> poly(false, 5f, 12.5f, 10f, 17f, 19f, 7f)
            Ico.CHEVRON -> poly(false, 6f, 9f, 12f, 15f, 18f, 9f)
            Ico.LOCK -> {
                drawRoundRect(tint, topLeft = p(5.5f, 11f), size = Size(13f * u, 9.5f * u), cornerRadius = CornerRadius(3f * u), style = st)
                drawArc(tint, startAngle = 180f, sweepAngle = 180f, useCenter = false, topLeft = p(8.5f, 4.5f), size = Size(7f * u, 7f * u), style = st)
                line(8.5f, 8f, 8.5f, 11f); line(15.5f, 8f, 15.5f, 11f)

            Ico.UP -> { line(12f, 20f, 12f, 8f); poly(false, 6f, 13f, 12f, 7f, 18f, 13f); line(5f, 3f, 19f, 3f) }
            Ico.BOLT -> poly(true, 13f, 3f, 5f, 13.5f, 11f, 13.5f, 10f, 21f, 19f, 10f, 13f, 10f)

@Composable
fun <T> Chips(options: List<Pair<T, String>>, selected: T, enabled: Boolean = true, onSelect: (T) -> Unit) {
    // Wraps onto the next line instead of running off the screen.
    FlowRow(
        Modifier.fillMaxWidth(),
        horizontalArrangement = Arrangement.spacedBy(8.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        options.forEach { (v, label) -> Pill(label, v == selected, enabled) { onSelect(v) } }
    }
}

/** Full-width segmented switch (2–3 options) used on the home screen. */
@Composable

    val c = MaterialTheme.colorScheme
    Row(
        Modifier.fillMaxWidth().alpha(if (enabled) 1f else 0.6f).clip(RoundedCornerShape(16.dp))
            .background(c.surfaceContainerHigh).padding(4.dp),
        horizontalArrangement = Arrangement.spacedBy(4.dp)
    ) {
        options.forEach { (v, label) ->
            val sel = v == selected
            val bg by animateColorAsState(if (sel) c.primary else Color.Transparent, label = "segBg")
            Box(

                contentAlignment = Alignment.Center

                    fontWeight = if (sel) FontWeight.SemiBold else FontWeight.Medium,
                    color = if (sel) c.onPrimary else c.onSurfaceVariant
                )
            }
        }
    }
}

@Composable
fun TextRow(
    title: String, value: String, hint: String = "", singleLine: Boolean = true, isError: Boolean = false,
    minHeight: androidx.compose.ui.unit.Dp = androidx.compose.ui.unit.Dp.Unspecified,
    maxHeight: androidx.compose.ui.unit.Dp = androidx.compose.ui.unit.Dp.Unspecified,
    onChange: (String) -> Unit
) {
    Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
        Label(title)
        // With a max height the box stops growing and scrolls inside itself, so a long list never pushes the rest of the page away.
        val size = if (maxHeight != androidx.compose.ui.unit.Dp.Unspecified)
            Modifier.heightIn(min = if (minHeight != androidx.compose.ui.unit.Dp.Unspecified) minHeight else 0.dp, max = maxHeight)
        else Modifier
        OutlinedTextField(
            value = value, onValueChange = onChange, singleLine = singleLine, isError = isError,
            shape = RoundedCornerShape(14.dp), colors = fieldColors(),
            placeholder = { if (hint.isNotEmpty()) Text(hint) }, modifier = Modifier.fillMaxWidth().then(size)
        )
    }
}

@Composable
fun NumberRow(title: String, value: Int, onChange: (Int) -> Unit) {
    var t by remember(value) { mutableStateOf(value.toString()) }
    Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
        Label(title)
        OutlinedTextField(
            value = t,
            onValueChange = { v ->
                t = v.filter { it.isDigit() }.take(5)
                t.toIntOrNull()?.let(onChange)
            },
            singleLine = true, shape = RoundedCornerShape(14.dp), colors = fieldColors(),
            modifier = Modifier.fillMaxWidth()
        )
    }
}

/**
 * Port field. The text is kept exactly as typed and a value is saved only once it is a valid, free
 * port, so a half-typed number never gets rewritten under the user's fingers.
 */
@Composable
fun PortRow(title: String, value: Int, otherPort: Int, errorText: String, otherPort2: Int = -1, onValid: (Int) -> Unit) {
    var t by remember { mutableStateOf(value.toString()) }
    val n = t.toIntOrNull()
    val bad = n == null || n !in 1024..65535 || n == TOR_PORT || n == PSIPHON_PORT || n == otherPort || n == otherPort2
    Column(verticalArrangement = Arrangement.spacedBy(8.dp)) {
        Label(title)
        OutlinedTextField(
            value = t,
            onValueChange = { v ->
                t = v.filter { it.isDigit() }.take(5)
                val x = t.toIntOrNull()
                if (x != null && x in 1024..65535 && x != TOR_PORT && x != PSIPHON_PORT && x != otherPort && x != otherPort2) onValid(x)
            },
            isError = bad,
            supportingText = if (bad) ({ Text(errorText) }) else null,
            singleLine = true, shape = RoundedCornerShape(14.dp), colors = fieldColors(),
            modifier = Modifier.fillMaxWidth()
        )
    }
}

package app.vpn8

import android.content.Context
import java.io.File
import java.util.concurrent.TimeUnit
import kotlin.concurrent.thread

/** Runs the Aether binary (shipped as libaether.so) as a child process. */
class CoreProcess(private val ctx: Context) {
    private var proc: Process? = null

    val alive: Boolean get() = proc?.isAlive == true

    @Volatile var psiphonReady = false
    /** Aether finished validating the tunnel and started its SOCKS server (the port can be open earlier). */
    @Volatile var socksReady = false
    /** Psiphon could not open its database (a leftover helper still holds the lock). */
    @Volatile var datastoreFailed = false

    fun start(allArgs: List<String>) {
        // NAME=value tokens in the extra arguments are environment variables, not flags.
        val envRe = Regex("^[A-Z][A-Z0-9_]*=.*")
        val args = allArgs.filterNot { envRe.matches(it) }
        val extraEnv = allArgs.filter { envRe.matches(it) }
        val nl = ctx.applicationInfo.nativeLibraryDir
        val dir = File(ctx.filesDir, "aether").apply { mkdirs() }
        val pb = ProcessBuilder(listOf("$nl/libaether.so") + args)
            .directory(dir)
            .redirectErrorStream(true)
        pb.environment().apply {
            put("HOME", dir.path)
            put("TMPDIR", ctx.cacheDir.path)
            put("AETHER_LOG_LEVEL", "info")
            for (kv in extraEnv) put(kv.substringBefore('='), kv.substringAfter('='))
            put("AETHER_TOR_PT", "obfs4=$nl/liblyrebird.so;webtunnel=$nl/liblyrebird.so")
        }
        Engine.log("exec: aether ${args.joinToString(" ")}")
        val p = pb.start()
        proc = p
        thread(isDaemon = true, name = "aether-log") {
            try {
                p.inputStream.bufferedReader().forEachLine {
                    if (it.contains("psiphon is ready")) psiphonReady = true
                    if (it.contains("socks5 server listening") || it.contains("tunnel validated")) socksReady = true
                    if (it.contains("tryDatastoreOpenDB") || it.contains("openDataStore")) datastoreFailed = true
                    Engine.log(it)
                }
            } catch (_: Exception) { }
            val code = try { if (p.waitFor(3, TimeUnit.SECONDS)) p.exitValue() else null } catch (_: Exception) { null }
            val why = when (code) {
                137 -> " = killed by Android (SIGKILL)"
                139 -> " = native crash (SIGSEGV)"
                134 -> " = aborted (SIGABRT)"
                143 -> " = stopped (SIGTERM)"
                else -> ""
            }
            Engine.log("core exited (code ${code ?: "unknown"})$why")
        }
    }

    /** SIGTERM first so Aether can stop Psiphon/Tor children, SIGKILL if it lingers. */
    fun stop(graceMs: Long = 1200) {
        val p = proc ?: return
        proc = null
        p.destroy()
        try {
            if (!p.waitFor(graceMs, TimeUnit.MILLISECONDS)) p.destroyForcibly()
        } catch (_: InterruptedException) {
            p.destroyForcibly()
        }
    }
}

/**
 * Kills helper processes of this app that a previous run left behind (aether, psiphon, lyrebird).
 * Stopping the core only signals aether itself; when it has to be SIGKILLed, its psiphon / tor helper
 * is orphaned and keeps the Psiphon datastore (or the SOCKS port) locked. Only processes of our own
 * uid are visible and killable, and only ones running our own native libraries are matched.
 */
object Leftovers {
    private val names = listOf("libaether.so", "libpsiphon.so", "liblyrebird.so")

    fun kill(): Int {
        val me = android.os.Process.myPid()
        var n = 0
        val dirs = File("/proc").listFiles() ?: return 0
        for (d in dirs) {
            val pid = d.name.toIntOrNull() ?: continue
            if (pid == me) continue
            val cmd = try { File(d, "cmdline").readText() } catch (_: Exception) { continue }
            if (names.any { cmd.contains(it) }) {
                try {
                    android.system.Os.kill(pid, android.system.OsConstants.SIGKILL)
                    n++
                } catch (_: Exception) { }
            }
        }
        return n
    }
}

import kotlinx.coroutines.flow.MutableStateFlow

enum class Phase { IDLE, CONNECTING, CONNECTED, RECONNECTING, STOPPING }

data class Status(val phase: Phase = Phase.IDLE, val attempt: Int = 0, val error: String? = null)

/** Process-wide connection state shared by the service, the tile and the UI. */
object Engine {
    val status = MutableStateFlow(Status())
    val pingMs = MutableStateFlow<Int?>(null)
    val rxBps = MutableStateFlow(0L)
    val txBps = MutableStateFlow(0L)
    val exitInfo = MutableStateFlow<String?>(null)
    /** Two-letter country code of the exit IP (null = unknown yet); drives the flag next to the status. */
    val exitCountry = MutableStateFlow<String?>(null)
    /** Measured download speed through the tunnel in bytes/s (null = not measured yet). */
    val speedBps = MutableStateFlow<Long?>(null)
    /** True while the VPN interface is switched off but the core keeps running (Stop button). */
    val paused = MutableStateFlow(false)
    val logs = MutableStateFlow<List<String>>(emptyList())
    /** Why the link last dropped (shown under the connect button); null = nothing dropped yet. */
    val lastReason = MutableStateFlow<String?>(null)

    private val ansi = Regex("\u001B\\[[0-9;]*[A-Za-z]")

    fun log(line: String) {
        val clean = ansi.replace(line, "").trimEnd()
        if (clean.isEmpty()) return
        val stamp = java.text.SimpleDateFormat("HH:mm:ss", java.util.Locale.US).format(java.util.Date())
        logs.value = (logs.value + "$stamp  $clean").takeLast(400)
    }

    fun resetLive() {
        pingMs.value = null
        rxBps.value = 0
        txBps.value = 0
        exitInfo.value = null
        exitCountry.value = null
        speedBps.value = null
    }
}

@Composable
fun ConnectButton(phase: Phase, onClick: () -> Unit, diameter: Dp = 158.dp) {

    val x = LocalExtra.current

    val busy = phase == Phase.CONNECTING || phase == Phase.RECONNECTING || phase == Phase.STOPPING

    val busyA by animateFloatAsState(if (busy) 1f else 0f, tween(300), label = "busyA")
    val ring = if (busy) x.busy else x.a
    val fg by animateColorAsState(
        when { live -> Color.White; busy -> Color(0xFF2B1E00); else -> c.onSurfaceVariant }, label = "fg"
    )

    Box(Modifier.size(diameter * 1.5f), contentAlignment = Alignment.Center) {
        Canvas(Modifier.fillMaxSize()) {
            if (glow > 0.01f) {
                val outer = this.size.minDimension / 2f
                val core = outer / 1.5f
                drawCircle(
                    Brush.radialGradient(listOf(ring.copy(alpha = 0.26f * glow), Color.Transparent), radius = outer),
                    radius = outer
                )
                for (i in 0 until 3) {
                    val p = (t + i / 3f) % 1f
                    drawCircle(
                        color = ring.copy(alpha = (1f - p) * 0.30f * glow),
                        radius = core + (outer - core) * p,
                        style = androidx.compose.ui.graphics.drawscope.Stroke(width = 1.5.dp.toPx())
                    )
                }
            }
        }
        Box(
            Modifier.size(diameter).scale(if (busy) breathe else 1f).clip(CircleShape)
                .background(c.surfaceContainerHigh).border(1.dp, c.outlineVariant, CircleShape)
                .clickable(onClick = onClick),
            contentAlignment = Alignment.Center
        ) {
            Box(Modifier.fillMaxSize().alpha(liveA).background(x.gradient))
            Box(Modifier.fillMaxSize().alpha(busyA).background(x.busy))

package app.vpn8

import java.net.Inet4Address
import java.net.NetworkInterface

/** Finds the IPv4 addresses other devices can use to reach this phone (hotspot, USB tethering, Wi-Fi). */
object LanShare {
    data class Addr(val iface: String, val ip: String)

    fun addresses(): List<Addr> = try {
        NetworkInterface.getNetworkInterfaces().toList()
            .filter { runCatching { it.isUp && !it.isLoopback }.getOrDefault(false) }
            .filterNot { it.name.startsWith("tun") || it.name.startsWith("dummy") || it.name.startsWith("rmnet") || it.name.startsWith("ccmni") || it.name.startsWith("v4-") || it.name.startsWith("clat") }
            .flatMap { nif ->
                nif.inetAddresses.toList()
                    .filterIsInstance<Inet4Address>()
                    .filter { !it.isLoopbackAddress && !it.isLinkLocalAddress }
                    .map { Addr(nif.name, it.hostAddress ?: "") }
            }
            .filter { it.ip.isNotEmpty() }
    } catch (_: Exception) {
        emptyList()
    }

    /** Addresses to show for a listen address: every device address for 0.0.0.0, the address itself otherwise. */
    fun targets(host: String, all: List<Addr> = addresses()): List<Addr> =
        if (host == "0.0.0.0") all else if (host == "127.0.0.1") emptyList() else listOf(Addr("", host))

    /** Addresses Android uses by default for a hotspot / USB tethering. Shown as a hint while no real address exists yet. */
    val guesses = listOf(Addr("wlan", "192.168.43.1"), Addr("rndis", "192.168.42.129"))

    /** Short human label for an interface name. */
    fun kind(iface: String): String = when {
        iface.startsWith("wlan") || iface.startsWith("swlan") || iface.startsWith("ap") -> "Wi-Fi / Hotspot"
        iface.startsWith("rndis") || iface.startsWith("usb") || iface.startsWith("eth") -> "USB / Ethernet"
        iface.isEmpty() -> "Custom"
        else -> iface
    }
}

object Hosts {
    fun valid(v: String): Boolean {
        val p = v.trim().split('.')
        return p.size == 4 && p.all { it.isNotEmpty() && it.length <= 3 && it.all(Char::isDigit) && it.toInt() <= 255 }
    }
    fun clean(v: String): String = if (valid(v)) v.trim() else "0.0.0.0"
}

/** Custom gateway helpers. Aether wants `ip:port` (IPv6 as `[addr]:port`). */
object Endpoints {
    private val re = Regex("""^(\d{1,3}(\.\d{1,3}){3}|\[[0-9a-fA-F:.]+\]):(\d{1,5})$""")

    /** Returns the trimmed endpoint if it is a valid ip:port, else null. */
    fun clean(v: String): String? {
        val t = v.trim()
        val m = re.matchEntire(t) ?: return null
        val port = m.groupValues[3].toIntOrNull() ?: return null
        if (port !in 1..65535) return null
        if (!t.startsWith("[") && t.substringBefore(':').split('.').any { (it.toIntOrNull() ?: 256) > 255 }) return null
        return t
    }

    fun valid(v: String) = v.isBlank() || clean(v) != null
}

object SettingsStore {
    private lateinit var prefs: SharedPreferences
    private val _flow = MutableStateFlow(Settings())
    val flow: StateFlow<Settings> = _flow
    val current: Settings get() = _flow.value

    fun init(ctx: Context) {
        if (::prefs.isInitialized) return
        prefs = ctx.applicationContext.getSharedPreferences("settings", Context.MODE_PRIVATE)
        _flow.value = load()
        val schema = prefs.getInt("schema", 0)
        if (schema < 5) {
            // One-time reset of the defaults: Aether + WireGuard first, MASQUE over HTTP/2,
            // quick reconnect on, and hev as the TUN engine.
            val d = Settings()
            val next = _flow.value.copy(
                route = d.route, protocol = d.protocol, carrier = d.carrier,
                quickReconnect = d.quickReconnect, tunEngine = d.tunEngine,
            )
            _flow.value = next
            save(next)
            prefs.edit().putInt("schema", 5).apply()
        }
        if (prefs.getInt("schema", 0) < 6) {
            // Base engine is hev again; tun2socks stays selectable in Settings.
            val next = _flow.value.copy(tunEngine = Settings().tunEngine)
            _flow.value = next
            save(next)
            prefs.edit().putInt("schema", 6).apply()
        }
        if (prefs.getInt("schema", 0) < 8) {
            // One-time tuning reset for weak / unstable networks. Language, theme, ports and
            // split-tunnel apps are kept; everything that shapes the connection is reset.
            val d = Settings()
            val next = _flow.value.copy(
                route = d.route, protocol = d.protocol, carrier = d.carrier,
                scan = d.scan, noize = d.noize, ipVersion = d.ipVersion,
                quickReconnect = d.quickReconnect, freshAfterDrop = d.freshAfterDrop,
                maxTries = d.maxTries, retryDelayMs = d.retryDelayMs,
                pingFails = d.pingFails, pingIntervalSec = d.pingIntervalSec,
                tunEngine = d.tunEngine, tunMtu = d.tunMtu, tcpBufferKb = d.tcpBufferKb,
                perf = d.perf, dns = d.dns, endpoint = d.endpoint, endpoint2 = d.endpoint2,
                extraArgs = d.extraArgs,
            )
            _flow.value = next
            save(next)
            prefs.edit().putInt("schema", 8).apply()
        }
        if (prefs.getInt("schema", 0) < 9) {
            // The default TUN engine is tun2socks (the same data path FCAE VPN uses), with an
            // automatic fallback to hev when it cannot start.
            val next = _flow.value.copy(tunEngine = Settings().tunEngine)
            _flow.value = next
            save(next)
            prefs.edit().putInt("schema", 9).apply()
        }
        if (prefs.getInt("schema", 0) < 10) {
            // Failed probes in a row before the link counts as dead: 4 -> 3. Connection attempts: 5 -> 3.
            val next = _flow.value.copy(pingFails = Settings().pingFails, maxTries = Settings().maxTries)
            _flow.value = next
            save(next)
            prefs.edit().putInt("schema", 10).apply()
        }
        if (prefs.getInt("schema", 0) < 11) {
            // The default TUN engine is now sing-box (falls back to hev when its library is missing).
            val next = _flow.value.copy(tunEngine = Settings().tunEngine)
            _flow.value = next
            save(next)
            prefs.edit().putInt("schema", 11).apply()
        }
    }

    fun update(f: (Settings) -> Settings) {
        val next = sanitize(f(_flow.value))
        _flow.value = next
        save(next)
    }

    private fun sanitize(s: Settings): Settings {
        val socks = if (s.socksPort in 1024..65535 && s.socksPort != TOR_PORT && s.socksPort != PSIPHON_PORT) s.socksPort else 1819
        var http = if (s.httpPort in 1024..65535 && s.httpPort != TOR_PORT && s.httpPort != PSIPHON_PORT) s.httpPort else 1822
        if (http == socks) http = if (socks == 1822) 1823 else 1822
        var all = if (s.shareAllPort in 1024..65535 && s.shareAllPort != TOR_PORT && s.shareAllPort != PSIPHON_PORT) s.shareAllPort else 1830
        if (all == socks || all == http) all = listOf(1830, 1831, 1832, 1833).first { it != socks && it != http }
        return s.copy(socksPort = socks, httpPort = http, shareAllPort = all)
    }

    private fun load(): Settings {
        val d = Settings()
        fun str(k: String, def: String) = prefs.getString(k, def) ?: def
        return Settings(
            language = str("language", d.language),
            theme = str("theme", d.theme),
            dynamicColor = prefs.getBoolean("dynamicColor", d.dynamicColor),
            vpnMode = prefs.getBoolean("vpnMode", d.vpnMode),
            tunEngine = str("tunEngine", d.tunEngine).let { if (it == "tun2socks") "singbox" else it }.takeIf { it == "singbox" || it == "hev" || it == "hev-tcp" } ?: d.tunEngine,
            autoStart = prefs.getBoolean("autoStart", d.autoStart),
            keepAwake = prefs.getBoolean("keepAwake", d.keepAwake),
            route = Route.values().firstOrNull { it.name == prefs.getString("route", null) } ?: d.route,
            protocol = Protocol.values().firstOrNull { it.name == prefs.getString("protocol", null) } ?: d.protocol,
            carrier = str("carrier", d.carrier),
            scan = str("scan", d.scan),
            noize = str("noize", d.noize),
            quickReconnect = prefs.getBoolean("quickReconnect", d.quickReconnect),
            maxTries = prefs.getInt("maxTries", d.maxTries),
            retryDelayMs = prefs.getInt("retryDelayMs", d.retryDelayMs),
            pingFails = prefs.getInt("pingFails", d.pingFails),
            pingIntervalSec = prefs.getInt("pingIntervalSec", d.pingIntervalSec),
            tunMtu = prefs.getInt("tunMtu", d.tunMtu),

/** Custom Tor bridge lines typed or pasted by the user (obfs4 and webtunnel work; the app ships lyrebird only). */
object TorBridges {
    private val supported = setOf("obfs4", "webtunnel")

    /** Cleans the text: one bridge per line, blank lines and # comments dropped, a leading "Bridge " removed. */
    fun lines(text: String): List<String> = text.lines()
        .map { it.trim() }
        .filter { it.isNotEmpty() && !it.startsWith("#") }
        .map { it.replace(Regex("^bridge\\s+", RegexOption.IGNORE_CASE), "").trim() }
        .filter { it.isNotEmpty() }

    /** The transport word of a line, or "" for a plain bridge (IP:port ...). */
    fun transport(line: String): String {
        val first = line.substringBefore(' ').lowercase()
        return if (first.isNotEmpty() && !first[0].isDigit() && first[0] != '[') first else ""
    }

    /** True when the app can run this bridge: plain, obfs4 or webtunnel. */
    fun usable(line: String): Boolean = transport(line).let { it.isEmpty() || it in supported }

    /** The file content in torrc shape (each line starts with "Bridge "), only usable lines. */
    fun fileText(text: String): String = lines(text).filter { usable(it) }.joinToString("\n") { "Bridge $it" }
}

private fun LogLine(line: String) {

/**
 * Quick Settings tile (the buttons in the status-bar pull-down, next to Wi-Fi, flashlight, ...).
 * Tap = connect / disconnect. Shows the live state while the panel is open.
 */
class QsTile : TileService() {
    private var scope: CoroutineScope? = null

    override fun onTileAdded() {
        SettingsStore.init(this)
        render(Engine.status.value.phase, Engine.paused.value)
    }

    override fun onStartListening() {
        SettingsStore.init(this)
        scope?.cancel()
        val sc = CoroutineScope(Dispatchers.Main)
        scope = sc
        sc.launch {
            combine(Engine.status, Engine.paused) { st, paused -> st.phase to paused }
                .collect { (phase, paused) -> render(phase, paused) }
        }
    }

    override fun onStopListening() {
        scope?.cancel()
        scope = null
    }

    private fun render(p: Phase, paused: Boolean) {
        val t = qsTile ?: return
        t.label = getString(R.string.app_name)
        t.icon = Icon.createWithResource(this, R.drawable.ic_stat)
        val (state, text) = when (p) {
            Phase.IDLE -> Tile.STATE_INACTIVE to R.string.disconnected
            Phase.CONNECTING -> Tile.STATE_ACTIVE to R.string.connecting
            Phase.RECONNECTING -> Tile.STATE_ACTIVE to R.string.reconnecting
            Phase.STOPPING -> Tile.STATE_UNAVAILABLE to R.string.stopping
            Phase.CONNECTED ->
                if (paused) Tile.STATE_INACTIVE to R.string.vpn_paused
                else Tile.STATE_ACTIVE to R.string.connected
        }
        t.state = state
        if (Build.VERSION.SDK_INT >= 29) t.subtitle = getString(text)
        t.updateTile()
    }

    override fun onClick() {
        SettingsStore.init(this)
        val st = Engine.status.value.phase
        when {
            st == Phase.STOPPING -> return
            // Core is running but the VPN interface is paused (Stop button in the app): bring it back.
            st == Phase.CONNECTED && Engine.paused.value -> TunnelService.resume(this)
            st != Phase.IDLE -> TunnelService.stop(this)
            else -> connect()
        }
    }

    private fun connect() {
        // VPN permission must be granted from an activity; open the app once, after that the tile works alone.
        if (SettingsStore.current.vpnMode && VpnService.prepare(this) != null) {
            openApp()
        } else {
            runCatching { TunnelService.start(this) }.onFailure { openApp() }
        }
    }

    @Suppress("DEPRECATION")
    private fun openApp() {
        val i = Intent(this, MainActivity::class.java).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        if (Build.VERSION.SDK_INT >= 34) {
            startActivityAndCollapse(
                PendingIntent.getActivity(this, 0, i, PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT)
            )
        } else {
            startActivityAndCollapse(i)
        }
    }
}

private fun up(f: (Settings) -> Settings) = SettingsStore.update(f)

@Composable
fun SettingsScreen(
    back: () -> Unit,
    openLogs: () -> Unit,
    openAbout: () -> Unit,
    openSplit: () -> Unit,
    onLanguageChanged: () -> Unit,
) {
    val ctx = LocalContext.current
    val s by SettingsStore.flow.collectAsStateWithLifecycle()
    val st by Engine.status.collectAsStateWithLifecycle()
    var confirmClear by remember { mutableStateOf(false) }
    var regionDialog by remember { mutableStateOf(false) }
    // One section open at a time; tap the header again to close it.
    var open by rememberSaveable { mutableStateOf<String?>(null) }
    fun toggle(id: String) { open = if (open == id) null else id }
    val idle = st.phase == Phase.IDLE

    Page(stringResource(R.string.settings), back, actions = {
        IconBtn(Ico.LOGS, openLogs)
        IconBtn(Ico.INFO, openAbout)
    }) {
        Column(Modifier.verticalScroll(rememberScrollState())) {
            Banner(stringResource(R.string.restart_note))

            // ---- General
            CollapsibleGroup(
                stringResource(R.string.sec_general), open == "general", { toggle("general") },
                subtitle = stringResource(if (s.vpnMode) R.string.mode_vpn else R.string.mode_proxy) + "  ·  " +
                    (if (s.language == "fa") "فارسی" else "English")
            ) {
                Field(stringResource(R.string.language)) {
                    Chips(listOf("en" to "English", "fa" to "فارسی"), s.language) { v ->
                        if (v != s.language) { up { it.copy(language = v) }; onLanguageChanged() }
                    }
                }
                Field(stringResource(R.string.theme)) {
                    Chips(
                        listOf("system" to stringResource(R.string.theme_system), "dark" to stringResource(R.string.theme_dark), "light" to stringResource(R.string.theme_light)),
                        s.theme
                    ) { v -> up { it.copy(theme = v) } }
                }
                if (Build.VERSION.SDK_INT >= 31) SwitchRow(stringResource(R.string.dynamic_color), s.dynamicColor) { v -> up { it.copy(dynamicColor = v) } }
                Field(stringResource(R.string.default_mode)) {
                    Chips(listOf(true to stringResource(R.string.mode_vpn), false to stringResource(R.string.mode_proxy)), s.vpnMode, enabled = idle) { v -> up { it.copy(vpnMode = v) } }
                    if (!idle) Hint(stringResource(R.string.locked_hint))
                }
                Field(stringResource(R.string.tun_engine)) {
                    Chips(listOf("singbox" to "sing-box", "hev" to "hev-socks5-tunnel", "hev-tcp" to "hev (TCP only)"), s.tunEngine) { v -> up { it.copy(tunEngine = v) } }
                }
                SwitchRow(stringResource(R.string.auto_start), s.autoStart) { v -> up { it.copy(autoStart = v) } }
                ActionRow(Ico.BOLT, stringResource(R.string.tile_add)) {
                    if (Build.VERSION.SDK_INT >= 33) {
                        val sb = ctx.getSystemService(android.app.StatusBarManager::class.java)
                        sb.requestAddTileService(
                            android.content.ComponentName(ctx, QsTile::class.java),
                            ctx.getString(R.string.app_name),
                            android.graphics.drawable.Icon.createWithResource(ctx, R.drawable.ic_stat),
                            ctx.mainExecutor
                        ) { }
                    } else {
                        Toast.makeText(ctx, ctx.getString(R.string.tile_add_hint), Toast.LENGTH_LONG).show()
                    }
                }
                SwitchRow(stringResource(R.string.keep_awake), s.keepAwake) { v -> up { it.copy(keepAwake = v) } }
                val batteryOk = ctx.getSystemService(android.os.PowerManager::class.java).isIgnoringBatteryOptimizations(ctx.packageName)
                ActionRow(Ico.BOLT, stringResource(if (batteryOk) R.string.battery_row_ok else R.string.battery_row_ask)) {
                    if (batteryOk) {
                        Toast.makeText(ctx, ctx.getString(R.string.battery_already), Toast.LENGTH_SHORT).show()
                    } else {
                        runCatching {
                            ctx.startActivity(
                                android.content.Intent(android.provider.Settings.ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS)
                                    .addFlags(android.content.Intent.FLAG_ACTIVITY_NEW_TASK)
                            )
                        }
                    }
                }
            }

            // ---- Split tunneling (its own section)
            CollapsibleGroup(
                stringResource(R.string.sec_split), open == "split", { toggle("split") },
                subtitle = when (s.splitMode) {
                    "include" -> stringResource(R.string.split_include) + "  ·  " + stringResource(R.string.split_summary, s.splitApps.size)
                    "exclude" -> stringResource(R.string.split_exclude) + "  ·  " + stringResource(R.string.split_summary, s.splitApps.size)
                    else -> stringResource(R.string.split_off)
                }
            ) {
                Field(stringResource(R.string.split_tunnel)) {
                    Chips(
                        listOf("off" to stringResource(R.string.split_off), "include" to stringResource(R.string.split_include), "exclude" to stringResource(R.string.split_exclude)),
                        s.splitMode
                    ) { v -> up { it.copy(splitMode = v) } }
                }
                if (s.splitMode != "off") {
                    ActionRow(Ico.SETTINGS, stringResource(R.string.split_summary, s.splitApps.size), onClick = openSplit)
                }
                if (!s.vpnMode) Hint(stringResource(R.string.split_vpn_only))
            }

            // ---- Core and protocol
            CollapsibleGroup(
                stringResource(R.string.sec_core), open == "core", { toggle("core") },
                subtitle = s.activeLabel()
            ) {
                Field(stringResource(R.string.protocol)) {
                    Chips(Protocol.values().map { it to it.label }, s.protocol) { v -> up { it.copy(protocol = v) } }
                }
                Field(stringResource(R.string.transport)) {
                    Chips(listOf("h3" to "HTTP/3 (QUIC)", "h2" to "HTTP/2 (TCP)"), s.carrier) { v -> up { it.copy(carrier = v) } }
                }
                Field(stringResource(R.string.scan_level)) {
                    Chips(listOf("turbo", "balanced", "thorough", "verified", "ironclad").map { it to it }, s.scan) { v -> up { it.copy(scan = v) } }
                }
                Field(stringResource(R.string.noize)) {
                    Chips(
                        listOf("default" to stringResource(R.string.noize_default)) + listOf("off", "light", "firewall", "balanced", "gfw", "aggressive").map { it to it },
                        s.noize
                    ) { v -> up { it.copy(noize = v) } }
                }
                Field(stringResource(R.string.ip_version)) {
                    Chips(listOf("4" to "IPv4", "6" to "IPv6", "dual" to "IPv4 + IPv6"), s.ipVersion) { v -> up { it.copy(ipVersion = v) } }
                }
                SwitchRow(stringResource(R.string.quick_reconnect), s.quickReconnect) { v -> up { it.copy(quickReconnect = v) } }
                SwitchRow(stringResource(R.string.fresh_after_drop), s.freshAfterDrop) { v -> up { it.copy(freshAfterDrop = v) } }
                NumberRow(stringResource(R.string.max_tries), s.maxTries) { v -> up { it.copy(maxTries = v) } }
                NumberRow(stringResource(R.string.retry_delay), s.retryDelayMs) { v -> up { it.copy(retryDelayMs = v) } }
                NumberRow(stringResource(R.string.ping_fails), s.pingFails) { v -> up { it.copy(pingFails = v) } }
                NumberRow(stringResource(R.string.ping_interval), s.pingIntervalSec) { v -> up { it.copy(pingIntervalSec = v) } }
                TextRow(
                    stringResource(if (s.protocol == Protocol.GOOL || s.protocol == Protocol.GOOL_CLASSIC || s.protocol == Protocol.MIM) R.string.endpoint_outer else R.string.endpoint),
                    s.endpoint, stringResource(R.string.endpoint_hint), isError = !Endpoints.valid(s.endpoint)
                ) { v -> up { it.copy(endpoint = v.trim()) } }
                if (s.protocol == Protocol.GOOL || s.protocol == Protocol.GOOL_CLASSIC || s.protocol == Protocol.MIM) {
                    TextRow(stringResource(R.string.endpoint_inner), s.endpoint2, stringResource(R.string.endpoint_hint), isError = !Endpoints.valid(s.endpoint2)) { v -> up { it.copy(endpoint2 = v.trim()) } }
                }
                if (!Endpoints.valid(s.endpoint) || !Endpoints.valid(s.endpoint2)) {
                    Hint(stringResource(R.string.endpoint_invalid), error = true)
                } else {
                    Hint(stringResource(R.string.endpoint_note))
                }
                TextRow(stringResource(R.string.upstream), s.upstream, stringResource(R.string.upstream_hint)) { v -> up { it.copy(upstream = v) } }
            }

            // ---- Routing
            CollapsibleGroup(stringResource(R.string.sec_routing), open == "routing", { toggle("routing") }) {
                TextRow(stringResource(R.string.route_block), s.routeBlock, stringResource(R.string.route_hint)) { v -> up { it.copy(routeBlock = v) } }
                TextRow(stringResource(R.string.route_direct), s.routeDirect, stringResource(R.string.route_hint)) { v -> up { it.copy(routeDirect = v) } }
                TextRow(stringResource(R.string.dns), s.dns, stringResource(R.string.dns_hint)) { v -> up { it.copy(dns = v) } }
            }

            // ---- Psiphon
            CollapsibleGroup(stringResource(R.string.sec_psiphon), open == "psiphon", { toggle("psiphon") }) {
                RegionButton(s, true) { regionDialog = true }
                Field(stringResource(R.string.psiphon_mode)) {
                    Chips(listOf("auto" to "Auto", "cdn" to "CDN"), s.psiphonMode) { v -> up { it.copy(psiphonMode = v) } }
                }
            }

            // ---- Tor
            CollapsibleGroup(
                stringResource(R.string.sec_tor), open == "tor", { toggle("tor") },
                subtitle = stringResource(R.string.bridges) + ": " + when (s.torBridges) {
                    "always" -> stringResource(R.string.bridges_always)
                    "never" -> stringResource(R.string.bridges_never)
                    "custom" -> stringResource(R.string.bridges_custom)
                    else -> stringResource(R.string.bridges_auto)
                }
            ) {
                Field(stringResource(R.string.bridges)) {
                    Chips(
                        listOf(
                            "auto" to stringResource(R.string.bridges_auto), "always" to stringResource(R.string.bridges_always),
                            "never" to stringResource(R.string.bridges_never), "custom" to stringResource(R.string.bridges_custom)
                        ),
                        s.torBridges
                    ) { v -> up { it.copy(torBridges = v) } }
                }
                if (s.torBridges == "custom") BridgeEditor(s)
            }

            // ---- Share SOCKS5 / HTTP: ports, sharing and the addresses you can connect to
            val exitPort = ArgBuilder.exitPort(s)
            val socksAll = Hosts.clean(s.socksHost) == "0.0.0.0"
            val httpAll = Hosts.clean(s.httpHost) == "0.0.0.0"
            // Local addresses only work when the proxy listens on this phone's loopback (not shared) or on every network.
            val socksLocalOk = !s.socksShare || socksAll
            val httpLocalOk = s.httpEnabled && (!s.httpShare || httpAll)
            CollapsibleGroup(
                stringResource(R.string.sec_share), open == "share", { toggle("share") },
                subtitle = (if (socksLocalOk) stringResource(R.string.proxy_info, "127.0.0.1:$exitPort") else "SOCKS5") +
                    if (s.httpActive) "  ·  " + stringResource(R.string.http_info, "127.0.0.1:${s.httpPort}") else ""
            ) {
                // Every address and port, live: shown as soon as sharing is switched on, before any device connects

                SwitchRow(stringResource(R.string.share_all), s.shareAll) { v -> up { it.copy(shareAll = v) } }
                if (s.shareAll) {
                    PortRow(
                        stringResource(R.string.share_all_port), s.shareAllPort, s.socksPort, stringResource(R.string.port_invalid),
                        otherPort2 = if (s.httpActive) s.httpPort else -1
                    ) { v -> up { it.copy(shareAllPort = v) } }
                    TextRow(stringResource(R.string.share_all_addr), s.shareAllHost, "0.0.0.0", isError = !Hosts.valid(s.shareAllHost)) { v -> up { it.copy(shareAllHost = v.trim()) } }
                    if (!Hosts.valid(s.shareAllHost)) Hint(stringResource(R.string.addr_invalid), error = true)
                    Hint(stringResource(R.string.share_all_note))
                }

                // SOCKS5 (always running: the app itself uses it)
                PortRow(stringResource(R.string.socks_port), s.socksPort, if (s.httpActive) s.httpPort else -1, stringResource(R.string.port_invalid), otherPort2 = if (s.shareAll) s.shareAllPort else -1) { v -> up { it.copy(socksPort = v) } }
                SwitchRow(stringResource(R.string.socks_share), s.socksShare) { v -> up { it.copy(socksShare = v) } }
                if (s.socksShare) {
                    TextRow(stringResource(R.string.socks_addr), s.socksHost, "0.0.0.0", isError = !Hosts.valid(s.socksHost)) { v -> up { it.copy(socksHost = v.trim()) } }
                    if (!Hosts.valid(s.socksHost)) Hint(stringResource(R.string.addr_invalid), error = true)
                }

                // HTTP proxy: "this phone" and "other devices" are two separate switches
                SwitchRow(stringResource(R.string.http_proxy), s.httpEnabled) { v -> up { it.copy(httpEnabled = v) } }
                SwitchRow(stringResource(R.string.http_share), s.httpShare) { v -> up { it.copy(httpShare = v) } }
                if (s.httpActive) {
                    PortRow(stringResource(R.string.http_port), s.httpPort, s.socksPort, stringResource(R.string.port_invalid), otherPort2 = if (s.shareAll) s.shareAllPort else -1) { v -> up { it.copy(httpPort = v) } }
                }
                if (s.httpShare) {
                    TextRow(stringResource(R.string.http_addr), s.httpHost, "0.0.0.0", isError = !Hosts.valid(s.httpHost)) { v -> up { it.copy(httpHost = v.trim()) } }
                    if (!Hosts.valid(s.httpHost)) Hint(stringResource(R.string.addr_invalid), error = true)
                }

                if (s.socksShare || s.httpShare || s.shareAll) {
                    Hint(stringResource(R.string.lan_howto))
                    Hint(stringResource(R.string.lan_warn), error = true)
                }
                Hint(stringResource(R.string.ports_note))
            }

            // ---- Advanced
            CollapsibleGroup(stringResource(R.string.sec_advanced), open == "advanced", { toggle("advanced") }) {
                Field(stringResource(R.string.perf_profile)) {
                    Chips(listOf("auto" to "Auto", "low" to "Low", "medium" to "Medium", "high" to "High"), s.perf) { v -> up { it.copy(perf = v) } }
                }
                TextRow(stringResource(R.string.extra_args), s.extraArgs, stringResource(R.string.extra_args_hint)) { v -> up { it.copy(extraArgs = v) } }
                NumberRow(stringResource(R.string.tun_mtu), s.tunMtu) { v -> up { it.copy(tunMtu = v) } }
                NumberRow(stringResource(R.string.tcp_buffer), s.tcpBufferKb) { v -> up { it.copy(tcpBufferKb = v) } }
                Hint(stringResource(R.string.tunnel_note))
                ActionRow(Ico.LOGS, stringResource(R.string.open_logs), onClick = openLogs)
            }

            // ---- Clear cache (its own section)
            CollapsibleGroup(
                stringResource(R.string.sec_cache), open == "cache", { toggle("cache") },
                subtitle = stringResource(R.string.clear_cache), danger = true
            ) {
                Hint(stringResource(R.string.clear_cache_warn))
                ActionRow(Ico.TRASH, stringResource(R.string.clear_cache), enabled = idle, danger = true) { confirmClear = true }
                if (!idle) Hint(stringResource(R.string.locked_hint))
            }
            Spacer(Modifier.height(32.dp))
        }
    }

    if (regionDialog) RegionDialog(s.psiphonRegion, onPick = { cc -> up { it.copy(psiphonRegion = cc) }; regionDialog = false }) { regionDialog = false }

    if (confirmClear) {
        AlertDialog(
            onDismissRequest = { confirmClear = false },
            shape = RoundedCornerShape(28.dp),
            containerColor = MaterialTheme.colorScheme.surfaceContainer,
            title = { Text(stringResource(R.string.clear_cache), fontWeight = FontWeight.Bold) },
            text = { Text(stringResource(R.string.clear_cache_warn)) },
            confirmButton = {
                TextButton(onClick = {
                    File(ctx.filesDir, "aether").deleteRecursively()
                    ctx.cacheDir.deleteRecursively()
                    confirmClear = false
                    Toast.makeText(ctx, R.string.cleared, Toast.LENGTH_SHORT).show()
                }) { Text(stringResource(R.string.confirm)) }
            },
            dismissButton = { TextButton(onClick = { confirmClear = false }) { Text(stringResource(R.string.cancel)) } }
        )
    }
}


/** One eye-catching box holding every address and port; tap a line to copy its host:port. */
@Composable
fun AddrBox(ctx: Context, title: String, lines: List<Pair<String, String>>, status: String) {
    val c = MaterialTheme.colorScheme
    val shape = RoundedCornerShape(18.dp)
    Column(
        Modifier.fillMaxWidth().clip(shape)
            .background(Brush.linearGradient(listOf(c.primary.copy(alpha = 0.30f), c.tertiary.copy(alpha = 0.24f))))
            .border(1.5.dp, c.primary, shape).padding(14.dp),
        verticalArrangement = androidx.compose.foundation.layout.Arrangement.spacedBy(10.dp)
    ) {
        Text(title, style = MaterialTheme.typography.labelLarge, fontWeight = FontWeight.Bold, color = c.primary)
        for ((label, addr) in lines) {
            Column(
                Modifier.fillMaxWidth().clip(RoundedCornerShape(12.dp)).background(c.surface.copy(alpha = 0.55f))
                    .clickable {
                        val cm = ctx.getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
                        cm.setPrimaryClip(ClipData.newPlainText("proxy", addr))
                        Toast.makeText(ctx, ctx.getString(R.string.copied_addr, addr), Toast.LENGTH_SHORT).show()
                    }.padding(horizontal = 12.dp, vertical = 9.dp)
            ) {
                Text(label, style = MaterialTheme.typography.labelSmall, color = c.onSurfaceVariant)
                Text(addr, fontFamily = FontFamily.Monospace, fontWeight = FontWeight.Bold, fontSize = 16.sp, color = c.onSurface)
            }
        }
        Text(status, style = MaterialTheme.typography.bodySmall, color = c.onSurface)
    }
}


/**
 * The box with every address you can use for SOCKS5 / HTTP: this phone, and other devices over the
 * hotspot / USB / Wi-Fi. It refreshes every 2 s, so the hotspot address appears the moment you turn the
 * hotspot on, and it already shows the ports while nothing is connected. Used in Settings and on Home.
 */
@Composable
fun ShareBox(s: Settings, phase: Phase) {
    val ctx = LocalContext.current
    val exitPort = ArgBuilder.exitPort(s)
    val socksAll = Hosts.clean(s.socksHost) == "0.0.0.0"
    val httpAll = Hosts.clean(s.httpHost) == "0.0.0.0"
    val socksLocalOk = !s.socksShare || socksAll
    val httpLocalOk = s.httpEnabled && (!s.httpShare || httpAll)
    val lan by produceState(initialValue = LanShare.addresses()) {
        while (true) {
            delay(2000)
            value = withContext(Dispatchers.IO) { LanShare.addresses() }
        }
    }
    val socksT = if (s.socksShare) LanShare.targets(Hosts.clean(s.socksHost), lan) else emptyList()
    val httpT = if (s.httpShare) LanShare.targets(Hosts.clean(s.httpHost), lan) else emptyList()
    // No hotspot / tethering address yet: show the ports on the usual default addresses instead of an empty box.
    val allAll = Hosts.clean(s.shareAllHost) == "0.0.0.0"
    val allT = if (s.shareAll) LanShare.targets(Hosts.clean(s.shareAllHost), lan) else emptyList()
    val noIpYet = (s.socksShare && socksAll && socksT.isEmpty()) || (s.httpShare && httpAll && httpT.isEmpty()) ||
        (s.shareAll && allAll && allT.isEmpty())
    val guess = stringResource(R.string.addr_guess)

    val lines = buildList {
        // The one shared address: SOCKS5 and HTTP on the same port, carrying the final output of the current mode
        if (s.shareAll) {
            if (allAll || Hosts.clean(s.shareAllHost) == "127.0.0.1") add(stringResource(R.string.addr_all_local) to "127.0.0.1:${s.shareAllPort}")
            for (a in allT) add(stringResource(R.string.addr_all_lan, LanShare.kind(a.iface)) to "${a.ip}:${s.shareAllPort}")
            if (allAll && allT.isEmpty()) {
                for (g in LanShare.guesses) add(stringResource(R.string.addr_all_lan, LanShare.kind(g.iface)) + " · " + guess to "${g.ip}:${s.shareAllPort}")
            }
        }
        if (socksLocalOk) add(stringResource(R.string.addr_socks_local) to "127.0.0.1:$exitPort")
        if (httpLocalOk) add(stringResource(R.string.addr_http_local) to "127.0.0.1:${s.httpPort}")
        for (a in socksT) add(stringResource(R.string.addr_socks_lan, LanShare.kind(a.iface)) to "${a.ip}:$exitPort")
        for (a in httpT) add(stringResource(R.string.addr_http_lan, LanShare.kind(a.iface)) to "${a.ip}:${s.httpPort}")
        if (s.socksShare && socksAll && socksT.isEmpty()) {
            for (g in LanShare.guesses) add(stringResource(R.string.addr_socks_lan, LanShare.kind(g.iface)) + " · " + guess to "${g.ip}:$exitPort")
        }
        if (s.httpShare && httpAll && httpT.isEmpty()) {
            for (g in LanShare.guesses) add(stringResource(R.string.addr_http_lan, LanShare.kind(g.iface)) + " · " + guess to "${g.ip}:${s.httpPort}")
        }
    }
    AddrBox(
        ctx, stringResource(R.string.share_current_title), lines,
        stringResource(if (phase == Phase.CONNECTED) R.string.share_active else R.string.share_inactive)
    )
    if (noIpYet) Hint(stringResource(R.string.lan_no_ip))
}

/** Opens the Tor Project's Telegram bot that hands out bridges (the Telegram app if installed, else the web link). */
fun openBridgeBot(ctx: Context) {
    val flags = android.content.Intent.FLAG_ACTIVITY_NEW_TASK
    val tg = android.content.Intent(android.content.Intent.ACTION_VIEW, android.net.Uri.parse("tg://resolve?domain=GetBridgesBot")).addFlags(flags)
    val web = android.content.Intent(android.content.Intent.ACTION_VIEW, android.net.Uri.parse("https://t.me/GetBridgesBot")).addFlags(flags)
    try {
        ctx.startActivity(tg)
    } catch (_: Exception) {
        try { ctx.startActivity(web) } catch (_: Exception) {
            Toast.makeText(ctx, ctx.getString(R.string.bridge_bot_failed), Toast.LENGTH_LONG).show()
        }
    }
}

/**
 * Custom Tor bridges: the text box, a button that opens the Telegram bot to get bridges, and a button that
 * pastes what you copied there. Used in Settings and on the Home screen.
 */
@Composable
fun BridgeEditor(s: Settings, enabled: Boolean = true) {
    val ctx = LocalContext.current
    val all = TorBridges.lines(s.torCustomBridges)
    val bad = all.filterNot { TorBridges.usable(it) }
    TextRow(
        stringResource(R.string.bridges_custom_title), s.torCustomBridges,
        stringResource(R.string.bridges_custom_hint), singleLine = false, isError = bad.isNotEmpty() || all.isEmpty(),
        minHeight = 120.dp, maxHeight = 200.dp
    ) { v -> if (enabled) up { it.copy(torCustomBridges = v) } }
    androidx.compose.foundation.layout.Row(horizontalArrangement = androidx.compose.foundation.layout.Arrangement.spacedBy(8.dp)) {
        TonalPill(Ico.SEND, stringResource(R.string.bridge_get_bot), enabled = true) { openBridgeBot(ctx) }
        TonalPill(Ico.PASTE, "", enabled = enabled) {
            val cm = ctx.getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
            val clip = cm.primaryClip?.getItemAt(0)?.coerceToText(ctx)?.toString().orEmpty()
            val add = TorBridges.lines(clip)
            if (add.isEmpty()) {
                Toast.makeText(ctx, ctx.getString(R.string.bridge_paste_empty), Toast.LENGTH_SHORT).show()

import java.io.BufferedInputStream
import java.io.ByteArrayOutputStream
import java.io.IOException
import java.io.InputStream
import java.io.OutputStream
import java.net.Inet4Address
import java.net.Inet6Address
import java.net.InetAddress

import java.util.concurrent.ExecutorService
import java.util.concurrent.Executors

/**
 * One address and one port that shares the FINAL output of whatever mode is connected
 * (Aether, Aether → Psiphon, Aether → Tor, Psiphon only, Tor only, reverse modes).
 *
 * The same port speaks both SOCKS5 and HTTP (the first byte tells them apart):
 *  - SOCKS5 clients are passed straight through to the exit SOCKS5 port of the current mode.
 *  - HTTP proxy clients (plain requests and CONNECT for HTTPS) are converted to SOCKS5 and sent to that same exit port.
 *
 * Because it always talks to the exit port, the laptop gets Psiphon's or Tor's output, not just the Aether one.
 */
object ShareGateway {
    @Volatile private var server: ServerSocket? = null
    @Volatile private var pool: ExecutorService? = null
    private val sockets: MutableSet<Socket> = Collections.synchronizedSet(HashSet())

    /** Starts listening. Returns null on success or a short error text. */
    @Synchronized
    fun start(listenHost: String, listenPort: Int, exitHost: String, exitPort: Int): String? {
        stop()
        val ss = try {
            ServerSocket().apply {
                reuseAddress = true
                bind(InetSocketAddress(InetAddress.getByName(listenHost), listenPort), 128)
            }
        } catch (e: Exception) {
            return e.message ?: e.javaClass.simpleName
        }
        val p = Executors.newCachedThreadPool { r -> Thread(r, "share-gw").apply { isDaemon = true } }
        server = ss
        pool = p
        Engine.log("Share gateway on $listenHost:$listenPort → exit $exitHost:$exitPort")
        Thread({
            while (!ss.isClosed) {
                val c = try { ss.accept() } catch (_: IOException) { break }
                track(c)
                try {
                    p.execute {
                        try { handle(p, c, exitHost, exitPort) } catch (_: Exception) { }
                        close(c)
                    }
                } catch (_: Exception) { close(c) }
            }
        }, "share-gw-accept").apply { isDaemon = true }.start()
        return null
    }

    @Synchronized
    fun stop() {
        runCatching { server?.close() }
        server = null
        val all = synchronized(sockets) { sockets.toList() }
        all.forEach { close(it) }
        runCatching { pool?.shutdownNow() }
        pool = null
    }

    private fun track(s: Socket) { sockets.add(s) }

    private fun close(s: Socket?) {
        if (s == null) return
        sockets.remove(s)
        runCatching { s.close() }
    }

    // ------------------------------------------------------------------ connection

    private fun handle(p: ExecutorService, c: Socket, exitHost: String, exitPort: Int) {
        c.tcpNoDelay = true
        runCatching { c.keepAlive = true }
        c.soTimeout = 20000 // only while the first bytes are read
        val inp = BufferedInputStream(c.getInputStream(), 16 * 1024)
        val out = c.getOutputStream()
        inp.mark(1)
        val first = inp.read()
        if (first < 0) return
        inp.reset()

        // SOCKS client: the exit port already speaks SOCKS5, so just connect the two sockets.
        if (first == 5 || first == 4) {
            val up = Socket()
            track(up)
            try {
                up.connect(InetSocketAddress(exitHost, exitPort), 8000)
                c.soTimeout = 0
                pipe(p, c, inp, out, up, up.getInputStream(), up.getOutputStream())
            } finally { close(up) }
            return
        }

        // HTTP proxy client
        val head = readHead(inp) ?: return
        val lines = head.split("\r\n")
        val reqLine = lines[0].split(" ")
        if (reqLine.size < 3) { reply(out, "400 Bad Request"); return }
        val method = reqLine[0]
        val target = reqLine[1]
        val version = reqLine[2]

        if (method.equals("CONNECT", true)) {
            val (host, port) = splitHostPort(target, 443) ?: run { reply(out, "400 Bad Request"); return }
            val up = try { socks5Connect(exitHost, exitPort, host, port) } catch (_: Exception) { reply(out, "502 Bad Gateway"); return }
            try {
                out.write("HTTP/1.1 200 Connection Established\r\n\r\n".toByteArray()); out.flush()
                c.soTimeout = 0
                pipe(p, c, inp, out, up, up.getInputStream(), up.getOutputStream())
            } finally { close(up) }
            return
        }

        // Plain HTTP: absolute-form request line ("GET http://host/path HTTP/1.1"), rewritten to origin-form.
        val headerLines = lines.drop(1).filter { it.isNotEmpty() }
        var hostPort: String
        var path: String
        if (target.startsWith("http://", true)) {
            val rest = target.substring(7)
            val slash = rest.indexOf('/')
            hostPort = if (slash >= 0) rest.substring(0, slash) else rest
            path = if (slash >= 0) rest.substring(slash) else "/"
        } else if (target.startsWith("/")) {
            hostPort = headerLines.firstOrNull { it.startsWith("Host:", true) }?.substringAfter(':')?.trim() ?: run { reply(out, "400 Bad Request"); return }
            path = target
        } else { reply(out, "400 Bad Request"); return }
        hostPort = hostPort.substringAfterLast('@')
        val (host, port) = splitHostPort(hostPort, 80) ?: run { reply(out, "400 Bad Request"); return }

        val up = try { socks5Connect(exitHost, exitPort, host, port) } catch (_: Exception) { reply(out, "502 Bad Gateway"); return }
        try {
            val sb = StringBuilder()
            sb.append(method).append(' ').append(path).append(' ').append(version).append("\r\n")
            var hasHost = false
            for (h in headerLines) {
                val name = h.substringBefore(':').trim().lowercase()
                if (name == "proxy-connection" || name == "proxy-authorization" || name == "connection" || name == "keep-alive") continue
                if (name == "host") hasHost = true
                sb.append(h).append("\r\n")
            }
            if (!hasHost) sb.append("Host: ").append(hostPort).append("\r\n")
            sb.append("Connection: close\r\n\r\n")
            val uo = up.getOutputStream()
            uo.write(sb.toString().toByteArray(Charsets.ISO_8859_1)); uo.flush()
            c.soTimeout = 0
            pipe(p, c, inp, out, up, up.getInputStream(), uo)
        } finally { close(up) }
    }

    private fun reply(out: OutputStream, status: String) {
        runCatching { out.write("HTTP/1.1 $status\r\nConnection: close\r\nContent-Length: 0\r\n\r\n".toByteArray()); out.flush() }
    }

    /** Reads the request head up to the blank line. Anything after it (a request body) stays in the stream. */
    private fun readHead(i: InputStream): String? {
        val b = ByteArrayOutputStream()
        var state = 0
        while (b.size() < 32 * 1024) {
            val x = i.read()
            if (x < 0) return null
            b.write(x)
            state = when {
                x == '\r'.code && (state == 0 || state == 2) -> state + 1
                x == '\n'.code && (state == 1 || state == 3) -> state + 1
                else -> 0
            }
            if (state == 4) return String(b.toByteArray(), Charsets.ISO_8859_1).removeSuffix("\r\n\r\n")
        }
        return null
    }

    private fun splitHostPort(v: String, defaultPort: Int): Pair<String, Int>? {
        val t = v.trim()
        if (t.isEmpty()) return null
        if (t.startsWith("[")) {
            val end = t.indexOf(']')
            if (end < 0) return null
            val host = t.substring(1, end)
            val port = if (t.length > end + 2 && t[end + 1] == ':') t.substring(end + 2).toIntOrNull() ?: return null else defaultPort
            return host to port
        }
        val idx = t.lastIndexOf(':')
        if (idx < 0) return t to defaultPort
        val port = t.substring(idx + 1).toIntOrNull() ?: return null
        if (port !in 1..65535) return null
        return t.substring(0, idx) to port
    }

    // ------------------------------------------------------------------ SOCKS5 towards the exit

    private fun readFully(i: InputStream, b: ByteArray) {
        var n = 0
        while (n < b.size) {
            val r = i.read(b, n, b.size - n)
            if (r < 0) throw IOException("eof")
            n += r
        }
    }

    private val v4 = Regex("""^\d{1,3}(\.\d{1,3}){3}$""")

    /** Opens a connection to host:port through the exit SOCKS5 proxy. Names are sent as names so Psiphon / Tor resolve them remotely. */
    private fun socks5Connect(exitHost: String, exitPort: Int, host: String, port: Int): Socket {
        val s = Socket()
        track(s)
        try {
            s.connect(InetSocketAddress(exitHost, exitPort), 8000)
            runCatching { s.tcpNoDelay = true; s.keepAlive = true }
            s.soTimeout = 60000 // Psiphon and Tor can take a long time to answer a new connection
            val o = s.getOutputStream()
            val i = s.getInputStream()
            o.write(byteArrayOf(5, 1, 0)); o.flush()
            val r = ByteArray(2); readFully(i, r)
            if (r[0] != 5.toByte() || r[1] != 0.toByte()) throw IOException("socks auth")
            val req = ByteArrayOutputStream()
            req.write(byteArrayOf(5, 1, 0))
            val lit: InetAddress? = if (v4.matches(host) || host.contains(':')) runCatching { InetAddress.getByName(host) }.getOrNull() else null
            when (lit) {
                is Inet4Address -> { req.write(1); req.write(lit.address) }
                is Inet6Address -> { req.write(4); req.write(lit.address) }
                else -> {
                    val hb = host.toByteArray(Charsets.ISO_8859_1)
                    if (hb.isEmpty() || hb.size > 255) throw IOException("bad host")
                    req.write(3); req.write(hb.size); req.write(hb)
                }
            }
            req.write(port shr 8); req.write(port and 255)
            o.write(req.toByteArray()); o.flush()
            val h = ByteArray(4); readFully(i, h)
            if (h[1] != 0.toByte()) throw IOException("socks refused " + h[1])
            val skip = when (h[3].toInt()) {
                1 -> 4 + 2
                4 -> 16 + 2
                else -> { val l = ByteArray(1); readFully(i, l); (l[0].toInt() and 0xff) + 2 }
            }
            readFully(i, ByteArray(skip))
            s.soTimeout = 0
            return s
        } catch (e: Exception) {
            close(s)
            throw e
        }
    }

    // ------------------------------------------------------------------ copy both ways

    private fun pipe(p: ExecutorService, a: Socket, aIn: InputStream, aOut: OutputStream, b: Socket, bIn: InputStream, bOut: OutputStream) {
        val done = CountDownLatch(1)
        try {
            p.execute {
                if (!copy(bIn, aOut)) { close(a); close(b) } else runCatching { a.shutdownOutput() }
                done.countDown()
            }
        } catch (_: Exception) { return }
        if (!copy(aIn, bOut)) { close(a); close(b) } else runCatching { b.shutdownOutput() }
        runCatching { done.await() }
    }

    /** Copies until the end of the stream. Returns false when it ended with an error (so both sides should be closed). */
    private fun copy(i: InputStream, o: OutputStream): Boolean {
        val buf = ByteArray(16 * 1024)
        return try {
            while (true) {
                val n = i.read(buf)
                if (n < 0) break
                o.write(buf, 0, n)
                o.flush()
            }
            true
        } catch (_: IOException) {
            false
        }
    }
}

import java.io.InputStream
import java.net.InetSocketAddress
import java.net.Socket

/** Tiny SOCKS5 client used for the ping probe and the exit-IP lookup. */
object Socks {
    private fun readFully(i: InputStream, b: ByteArray) {
        var n = 0
        while (n < b.size) {
            val r = i.read(b, n, b.size - n)
            if (r < 0) throw java.io.IOException("eof")
            n += r
        }
    }

    /**
     * Downloads up to [maxBytes] of [path] over plain HTTP through the local SOCKS5 proxy and
     * returns (HTTP status, body bytes received, milliseconds), or null when no HTTP answer
     * arrived. Stops after [budgetMs] so a dead-slow link cannot block for long.
     */
    fun download(port: Int, host: String, path: String, maxBytes: Long, budgetMs: Long): Triple<Int, Long, Long>? = try {
        Socket().use { s ->
            s.connect(InetSocketAddress(LocalHost.host, port), 5000)
            s.soTimeout = 5000
            val o = s.getOutputStream()
            val i = s.getInputStream()
            o.write(byteArrayOf(5, 1, 0)); o.flush()
            val r = ByteArray(2); readFully(i, r)
            if (r[0] != 5.toByte() || r[1] != 0.toByte()) throw java.io.IOException("auth")
            val hb = host.toByteArray()
            o.write(byteArrayOf(5, 1, 0, 3, hb.size.toByte()) + hb + byteArrayOf(0, 80)); o.flush()
            val h = ByteArray(4); readFully(i, h)
            if (h[1] != 0.toByte()) throw java.io.IOException("connect refused")
            val skip = when (h[3].toInt()) {
                1 -> 4 + 2
                4 -> 16 + 2
                else -> { val l = ByteArray(1); readFully(i, l); (l[0].toInt() and 0xff) + 2 }
            }
            readFully(i, ByteArray(skip))
            val t0 = System.nanoTime()
            o.write("GET $path HTTP/1.1\r\nHost: $host\r\nConnection: close\r\n\r\n".toByteArray()); o.flush()

            val head = StringBuilder()
            val buf = ByteArray(16 * 1024)
            var body = 0L
            var status = 0
            var headDone = false
            val deadline = t0 + budgetMs * 1_000_000
            try {
                while (System.nanoTime() < deadline) {
                    val n = i.read(buf)
                    if (n < 0) break
                    if (!headDone) {
                        head.append(String(buf, 0, n, Charsets.ISO_8859_1))
                        val end = head.indexOf("\r\n\r\n")
                        if (end >= 0) {
                            headDone = true
                            status = head.substring(0, head.indexOf("\r\n")).split(" ").getOrNull(1)?.toIntOrNull() ?: 0
                            body = (head.length - (end + 4)).toLong()
                        } else if (head.length > 8192) break
                    } else {
                        body += n
                    }
                    if (headDone && (status != 200 || body >= maxBytes)) break
                }
            } catch (_: java.net.SocketTimeoutException) { }
            if (!headDone) throw java.io.IOException("no header")
            Triple(status, body, (System.nanoTime() - t0) / 1_000_000)
        }
    } catch (_: Exception) {
        null
    }

    /** Returns (milliseconds to first response byte, response text) or null on failure. */
    fun httpGet(port: Int, host: String, path: String, timeoutMs: Int): Pair<Long, String>? = try {
        Socket().use { s ->
            s.connect(InetSocketAddress(LocalHost.host, port), timeoutMs)
            s.soTimeout = timeoutMs
            val o = s.getOutputStream()
            val i = s.getInputStream()
            val t0 = System.nanoTime()
            o.write(byteArrayOf(5, 1, 0)); o.flush()
            val r = ByteArray(2); readFully(i, r)
            if (r[0] != 5.toByte() || r[1] != 0.toByte()) throw java.io.IOException("auth")
            val hb = host.toByteArray()
            o.write(byteArrayOf(5, 1, 0, 3, hb.size.toByte()) + hb + byteArrayOf(0, 80)); o.flush()
            val h = ByteArray(4); readFully(i, h)
            if (h[1] != 0.toByte()) throw java.io.IOException("connect refused")
            val skip = when (h[3].toInt()) {
                1 -> 4 + 2
                4 -> 16 + 2
                else -> { val l = ByteArray(1); readFully(i, l); (l[0].toInt() and 0xff) + 2 }
            }
            readFully(i, ByteArray(skip))
            o.write("GET $path HTTP/1.1\r\nHost: $host\r\nConnection: close\r\n\r\n".toByteArray()); o.flush()
            val first = i.read()
            if (first < 0) throw java.io.IOException("empty")
            val ms = (System.nanoTime() - t0) / 1_000_000
            val sb = StringBuilder().append(first.toChar())
            val buf = ByteArray(1024)
            try {
                while (sb.length < 4096) {
                    val n = i.read(buf)
                    if (n < 0) break
                    sb.append(String(buf, 0, n))
                }
            } catch (_: Exception) { }
            ms to sb.toString()
        }
    } catch (_: Exception) {
        null
    }
}

            else -> startSession()

        // is on, Android starts the service again and it reconnects, instead of staying off.
        return START_STICKY

    private fun startSession() {
        promote()
        if (stopping || job?.isActive == true) return
        val s = SettingsStore.current
        Engine.logs.value = emptyList()
        Engine.lastReason.value = null
        Engine.resetLive()
        Engine.paused.value = false
        Engine.status.value = Status(Phase.CONNECTING, 1)
        networkChanged = false
        psiSlot = 0
        watchNetwork()
        job = scope.launch { run(s) }
    }

    /** Stop button: closes the VPN interface (key icon gone) but leaves the core running. */
    private fun pauseVpn() {
        if (stopping || Engine.paused.value) return
        if (Engine.status.value.phase != Phase.CONNECTED || !SettingsStore.current.vpnMode) return
        Engine.paused.value = true
        scope.launch {
            withContext(Dispatchers.IO) { stopTunSide() }
            Engine.rxBps.value = 0
            Engine.txBps.value = 0
            Engine.log("VPN paused: interface off, core still running")
        }
    }

    /** Start button: brings the VPN interface back on the already running core, so it is instant. */
    private fun resumeVpn() {
        if (stopping || !Engine.paused.value) return
        val s = curSettings ?: return
        val port = curPort
        scope.launch {
            val ok = withContext(Dispatchers.IO) {
                synchronized(this@TunnelService) { if (tun == null) bringUpTun(s, port) else true }
            }
            if (ok) {
                lastRxAt = SystemClock.elapsedRealtime()
                Engine.paused.value = false
                Engine.log("VPN resumed")
            } else {
                Engine.log("Could not bring the VPN back, try again")
            }
        }
    }

    private fun stopSession() {
        if (stopping) return
        stopping = true
        Engine.status.value = Status(Phase.STOPPING)
        scope.launch {
            // Cancel first so the run loop cannot start a new core, then close the TUN and kill the
            // core right away: probes blocked on the local SOCKS port fail at once instead of
            // waiting for their 8-20 s timeouts, and the VPN key icon disappears immediately.
            job?.cancel()
            withContext(Dispatchers.IO) {
                stopTunSide()
                val c = core
                core = null
                c?.stop()
            }
            job?.join()
            finish(null)
            stopping = false
        }
    }

    private suspend fun finish(error: String?) {

        Engine.resetLive()
        Engine.paused.value = false
        Engine.status.value = Status(Phase.IDLE, error = error)

        stopForeground(STOP_FOREGROUND_REMOVE)
        stopSelf()

    private suspend fun run(base: Settings) {
        var s = base
        LocalHost.host = s.localHost()
        val port = ArgBuilder.exitPort(s)
        curPort = port
        var failures = 0
        var cycle = 0
        var everUp = false
        var forceFresh = false
        acquireWake(s)

        // Helpers left behind by an earlier run would hold our ports, and a stale core would make
        // the port check below look like a working connection.
        val killed = withContext(Dispatchers.IO) { Leftovers.kill() }
        if (killed > 0) {
            Engine.log("Stopped $killed leftover helper process(es) from an earlier run")
            delay(400)
        }
        val ports = buildList {
            add(s.socksPort)
            if (s.route.usesPsiphon && s.route != Route.PSIPHON_ONLY) add(PSIPHON_PORT)
            if (s.route.usesTor && s.route != Route.TOR_ONLY) add(TOR_PORT)
            if (s.httpActive) add(s.httpPort)
        }.distinct()
        val busy = withContext(Dispatchers.IO) { ports.firstOrNull { portOpen(it) } }
        if (busy != null) {
            finish(getString(R.string.port_busy, busy))
            return
        }
        // One address + port that shares the final output of the current mode (Aether / Psiphon / Tor) with other devices.
        if (s.shareAll) {
            val err = withContext(Dispatchers.IO) {
                ShareGateway.start(Hosts.clean(s.shareAllHost), s.shareAllPort, LocalHost.host, port)
            }
            if (err != null) {
                finish(getString(R.string.share_all_failed, err))
                return
            }
        }

        while (currentCoroutineContext().isActive) {
            val attempt = failures + 1
            Engine.status.value = Status(if (everUp) Phase.RECONNECTING else Phase.CONNECTING, attempt)
            if (everUp) awaitNetwork()
            val fresh = cycle > 0 || forceFresh
            forceFresh = false
            Engine.log("Starting core, attempt $attempt of ${s.tries()}" + if (fresh) " (fresh scan)" else "")

            if (startCore(s, port, fresh = fresh)) {
                curSettings = s
                // While paused (Stop button) the core runs but the VPN interface stays off.
                if (s.vpnMode && tun == null && !Engine.paused.value && !bringUpTun(s, port)) {
                    finish(getString(R.string.vpn_iface_failed))
                    return
                }
                everUp = true
                failures = 0
                cycle = 0
                networkChanged = false
                connectedAt = SystemClock.elapsedRealtime()
                lastRxAt = connectedAt
                Engine.status.value = Status(Phase.CONNECTED)
                Engine.log("Connected via ${s.activeLabel()}")
                scope.launch { fetchExit(port) }
                val speedJob = scope.launch {
                    // Only measures and shows the speed. It no longer restarts the core: a restart
                    // in the middle of a user's download cuts that download.
                    checkSpeed(port)
                }
                monitor(s, port)
                speedJob.cancel()
                Engine.pingMs.value = null
                Engine.exitInfo.value = null
                Engine.exitCountry.value = null
                Engine.speedBps.value = null
                if (networkChanged) {
                    // Wi-Fi <-> mobile data (or a new Wi-Fi): the old sockets are dead, so reconnect at
                    // once with quick reconnect instead of waiting for the pings to fail.
                    networkChanged = false
                    Engine.log("Network changed: reconnecting right away")
                    stopCore()
                    delay(s.retryMs())
                    continue
                }
                if (rescanRequested) {
                    Engine.lastReason.value = getString(R.string.reason_rescan)
                    rescanRequested = false
                    forceFresh = true
                    Engine.log("Rescan requested: restarting the core with a fresh scan")
                    stopCore()
                    delay(1000)
                    continue
                }
                // The gateway that just dropped is often the very one being throttled, so a drop is
                // followed by a fresh scan instead of reusing it (same rule as the Windows app).
                if (s.freshAfterDrop) forceFresh = true
                // The link died after being up. QUIC (h3) is often cut by the network after a few
                // seconds, so alternate between h3 and h2 on each drop to find one that stays up.
                if (s.route.family == Family.AETHER && !s.route.noWarp &&
                    (s.protocol == Protocol.MASQUE || s.protocol == Protocol.MIM)
                ) {
                    val next = if (s.carrier == "h3") "h2" else "h3"
                    Engine.log("Link dropped. Trying ${next.uppercase()} on the next attempt")
                    s = s.copy(carrier = next)
                }
            } else {
                failures++
                Engine.lastReason.value = getString(R.string.reason_start, attempt)
                if (s.route.usesPsiphon && core?.datastoreFailed == true) {
                    psiSlot++
                    Engine.log("Psiphon could not open its data folder: the next attempt uses a fresh one")
                }
                if (failures >= s.tries()) {
                    failures = 0
                    cycle++
                    if (cycle >= 2) {
                        if (!everUp) {
                            stopCore()
                            finish(getString(R.string.connect_failed))
                            return
                        }
                        // The link worked before, so a failure now is usually the phone being offline
                        // (screen off, Doze, no signal). Do not turn the VPN off: keep trying slowly
                        // and come back by itself when the network returns.
                        cycle = 1
                        Engine.log("Still offline. The VPN stays on and keeps trying every 20 s")
                        stopCore()
                        delay(20_000)
                    }
                    Engine.log("No luck. Dropping everything and starting over with a fresh scan")
                }
            }
            stopCore()
            delay(s.retryMs())
        }
    }

    /** Waits (without burning connection attempts) until the phone has a real network again. */
    private suspend fun awaitNetwork() {
        val cm = getSystemService(ConnectivityManager::class.java) ?: return
        var logged = false
        while (currentCoroutineContext().isActive && cm.activeNetwork == null) {
            if (!logged) { Engine.log("No network. Waiting for it to come back"); logged = true }
            delay(2000)
        }
    }

    // ------------------------------------------------------------------- core

    private suspend fun startCore(s: Settings, port: Int, fresh: Boolean): Boolean {
        withContext(Dispatchers.IO) {
            Leftovers.kill()
            cleanPsiphonDirs()
        }
        val c = CoreProcess(this)
        core = c
        try {
            c.start(ArgBuilder.build(this, s, fresh, psiSlot))
        } catch (e: Exception) {
            Engine.log("Could not start core: ${e.message}")
            return false
        }
        // How long a first route search may take before it counts as a failed attempt. Same numbers
        // as the Windows app: a slow search on a bad network is not a failure.
        val limit = when {
            s.route.usesTor -> 720_000L
            s.route.usesPsiphon -> 420_000L
            else -> 300_000L
        }
        val deadline = SystemClock.elapsedRealtime() + limit
        // Tor opens its SOCKS port at once, long before a circuit works. So for Tor routes the
        // connection only counts as up after a real request has gone through it.
        var torOk = !s.route.usesTor
        var lastTorProbe = 0L
        var torLogged = false
        while (currentCoroutineContext().isActive && SystemClock.elapsedRealtime() < deadline) {
            if (!c.alive) return false
            val waited = SystemClock.elapsedRealtime() - (deadline - limit)
            // Aether opens the Psiphon/Tor port immediately and only starts the SOCKS port once the
            // WARP tunnel is validated, so wait for both, plus Psiphon's own "ready" line.
            val ready = withContext(Dispatchers.IO) {
                portOpen(port) && (port == s.socksPort || portOpen(s.socksPort))
            } && (!s.route.usesPsiphon || c.psiphonReady || waited > 60_000) &&
                // Plain Aether: the port can accept connections before the tunnel is validated, so do
                // not bring up the VPN (or show Connected) until Aether says it is really ready.
                (s.route != Route.AETHER || c.socksReady || waited > 90_000)
            if (ready && !torOk) {
                val now = SystemClock.elapsedRealtime()
                if (now - lastTorProbe >= 3_000) {
                    lastTorProbe = now
                    if (!torLogged) { Engine.log("Waiting until Tor really carries traffic"); torLogged = true }
                    torOk = withContext(Dispatchers.IO) {
                        Socks.httpGet(port, "cp.cloudflare.com", "/generate_204", 15_000)
                            ?: Socks.httpGet(port, "www.gstatic.com", "/generate_204", 15_000)
                    } != null
                    if (torOk) Engine.log("Tor is carrying traffic")
                }
            }
            if (ready && torOk) return true
            delay(500)
        }
        return false
    }

    /** Deletes Psiphon data folders from earlier slots (a failed one may be broken or locked). */

        val keep = if (psiSlot == 0) "psiphon" else "psiphon-$psiSlot"
        File(filesDir, "aether").listFiles()?.forEach {
            if (it.isDirectory && (it.name == "psiphon" || it.name.startsWith("psiphon-")) && it.name != keep) {

    private suspend fun stopCore() {
        val c = core ?: return
        core = null
        withContext(Dispatchers.IO) { c.stop() }
    }

    private fun portOpen(port: Int): Boolean = try {
        Socket().use { it.connect(InetSocketAddress(LocalHost.host, port), 300) }
        true
    } catch (_: Exception) {
        false
    }

    /**
     * Returns when the link is considered dead: core exited, or too many probes in a row failed
     * while no data was flowing either.
     *
     * Psiphon and Tor are slow to answer and often stall a single new connection for many seconds
     * while the rest of the traffic is fine, so for those routes the monitor is more patient:
     * longer probe timeout, a higher failure limit, a longer pause between probes, and any data
     * that arrived in the last 20 s proves the link is alive. Dropping a working link is worse
     * than waiting a little longer: every drop restarts the core and throws the gateway away.
     */
    private suspend fun monitor(s: Settings, port: Int) {
        val slow = s.route.slow
        val timeout = if (slow) 25_000 else 8_000
        val limit = if (slow) maxOf(s.pingLimit(), 5) else s.pingLimit()
        val ticks = (if (slow) maxOf(s.pingEverySec(), 8) else s.pingEverySec()) * 2
        val aliveWindowMs = if (slow) 20_000L else 0L
        var fails = 0
        while (currentCoroutineContext().isActive) {
            if (rescanRequested || networkChanged) return
            if (core?.alive != true) {
                Engine.log("Core is not running anymore")
                Engine.lastReason.value = getString(R.string.reason_core)
                return
            }
            val r = withContext(Dispatchers.IO) {
                Socks.httpGet(port, "cp.cloudflare.com", "/generate_204", timeout)
                    ?: Socks.httpGet(port, "www.gstatic.com", "/generate_204", timeout)
            }
            if (networkChanged) return
            val now = SystemClock.elapsedRealtime()
            val recentData = Engine.rxBps.value > 0 || (aliveWindowMs > 0 && now - lastRxAt < aliveWindowMs)
            if (r != null) {
                fails = 0
                Engine.pingMs.value = r.first.toInt()
            } else if (recentData) {
                // The probe is starved by a busy download or is just slow, but data is arriving: the link is alive.
                fails = 0
                Engine.pingMs.value = null
            } else {
                fails++
                Engine.pingMs.value = null
                Engine.log("Ping failed ($fails/$limit), last data ${(now - lastRxAt) / 1000} s ago")
                if (fails >= limit) {
                    Engine.lastReason.value = getString(R.string.reason_pings, limit)
                    return
                }
            }
            // Wait between probes, but react to a rescan request or a network change within half a second.
            repeat(ticks) {
                if (rescanRequested || networkChanged) return
                delay(500)
            }
        }
    }

    /**
     * Downloads a small file through the tunnel and publishes the speed. Returns true when the link
     * is clearly too slow (a reason to look for a better gateway); false when it is fine or when
     * the test could not run at all.
     */
    private suspend fun checkSpeed(port: Int): Boolean {
        delay(2000) // let the tunnel settle
        val hosts = listOf(
            "speed.cloudflare.com" to "/__down?bytes=1000000",
            "cachefly.cachefly.net" to "/1mb.test",
            "ipv4.download.thinkbroadband.com" to "/1MB.zip",
        )
        for ((host, path) in hosts) {
            val r = withContext(Dispatchers.IO) { Socks.download(port, host, path, 1_000_000, 10_000) } ?: continue
            val (status, bytes, ms) = r
            if (status != 200 || bytes <= 0 || ms <= 0) continue
            val bps = bytes * 1000 / ms
            Engine.speedBps.value = bps
            Engine.log("Speed test: ${bps / 1024} KB/s ($bytes bytes in $ms ms via $host)")
            return bps < SLOW_BPS
        }
        Engine.log("Speed test: no result")
        return false
    }

    private suspend fun fetchExit(port: Int) {
        // The tunnel (especially Psiphon) may need a moment: retry a few times before giving up.
        var r: Pair<Long, String>? = null
        for (i in 0 until 4) {
            r = withContext(Dispatchers.IO) { Socks.httpGet(port, "www.cloudflare.com", "/cdn-cgi/trace", 15_000) }
            if (r != null) break
            delay(3000)
        }
        if (r == null) return
        val map = r.second.lines().mapNotNull { l -> l.split("=", limit = 2).takeIf { it.size == 2 } }.associate { it[0] to it[1].trim() }
        val ip = map["ip"] ?: return
        Engine.exitInfo.value = if (map["loc"] != null) "$ip (${map["loc"]})" else ip
        Engine.exitCountry.value = map["loc"]?.trim()?.uppercase()?.takeIf { it.length == 2 && it.all { ch -> ch in 'A'..'Z' } }
    }

    /**
     * Watches the physical default network. This app is excluded from its own VPN, so the default
     * network it sees is the real Wi-Fi / mobile one, not the TUN.
     */
    private fun watchNetwork() {
        if (netCb != null) return
        val cm = getSystemService(ConnectivityManager::class.java) ?: return
        val cb = object : ConnectivityManager.NetworkCallback() {
            override fun onAvailable(network: Network) {
                val prev = lastNet
                lastNet = network
                if (prev != null && prev != network &&
                    Engine.status.value.phase == Phase.CONNECTED &&
                    SystemClock.elapsedRealtime() - connectedAt > 3000
                ) {
                    Engine.lastReason.value = getString(R.string.reason_network)
                    Engine.log("Default network changed")
                    networkChanged = true
                }
            }
        }
        try {
            cm.registerDefaultNetworkCallback(cb)
            netCb = cb
        } catch (e: Exception) {
            Engine.log("Network watcher unavailable: ${e.message}")
        }
    }

    private fun unwatchNetwork() {
        val cb = netCb ?: return
        netCb = null
        lastNet = null
        runCatching { getSystemService(ConnectivityManager::class.java)?.unregisterNetworkCallback(cb) }
    }

    // -------------------------------------------------------------------- tun

    private fun bringUpTun(s: Settings, port: Int): Boolean {
        val b = Builder()
            .setSession("8 VPN")
            .setMtu(s.mtu())
            .addAddress("198.18.0.1", 32)
            .addRoute("0.0.0.0", 0)

        // IPv6 on the TUN only when the exit can carry it. With an IPv4-only exit (the default, and
        // always for Psiphon/Tor), an IPv6 address + ::/0 route makes apps connect to the AAAA
        // answer first; the core cannot dial it and downloads stall or get cut.
        // "Remote names" mode: Psiphon/Tor exits (TCP only) and the hev-tcp engine. Apps ask hev's
        // local DNS (198.18.0.2) which hands out fake addresses; the core resolves the real name.
        // No UDP goes through the tunnel at all in this mode.
        // With sing-box the names are resolved by sing-box itself (DNS over TCP through the proxy),
        // so the TUN keeps real resolver addresses and no fake-address mode is needed.
        val useSb = s.tunEngine == "singbox" && SingBox.available
        if (s.tunEngine == "singbox" && !useSb) Engine.log("sing-box library is not in this build, using hev-socks5-tunnel")
        val remoteDns = !useSb && (s.route.slow || s.tunEngine == "hev-tcp")
        val v6 = s.ipVersion != "4" && !s.route.slow && !remoteDns
        if (v6) {
            b.addAddress("fc00::1", 128)
            b.addRoute("::", 0)
        }

        // Real resolvers, reached through the tunnel (UDP/53 -> hev -> SOCKS UDP ASSOCIATE -> core).
        // Apps and Android then cache the answers and connect by IP, instead of every new TCP
        // connection making the core do its own uncached DNS lookup over the slow link.
        // Psiphon/Tor exits carry TCP only, so there names are resolved remotely (hev mapdns).
        if (remoteDns) b.addDnsServer("198.18.0.2") else tunDnsServers(s).forEach { runCatching { b.addDnsServer(it) } }

        val apps = s.splitApps
        try {
            if (s.splitMode == "include" && apps.isNotEmpty()) {
                apps.forEach { runCatching { b.addAllowedApplication(it) } }
            } else {
                // The core's own sockets must never loop back into the tunnel.
                b.addDisallowedApplication(packageName)
                if (s.splitMode == "exclude") apps.forEach { runCatching { b.addDisallowedApplication(it) } }
            }
        } catch (e: Exception) {
            Engine.log("Split tunneling error: ${e.message}")
        }

        val fd = b.establish() ?: return false
        tun = fd
        Engine.log("TUN up: engine=${s.tunEngine}, mtu=${s.mtu()}, dns=" + (if (remoteDns) "remote" else tunDnsServers(s).joinToString(",")))

        if (useSb) {
            if (startSingBox(fd, port, s, v6)) return true
            Engine.log("sing-box failed to start, falling back to hev-socks5-tunnel")
            runCatching { fd.close() }
            tun = null
            return bringUpTun(s.copy(tunEngine = "hev"), port)
        }

        if (s.tunEngine == "tun2socks") {
            if (s.route.slow) {
                Engine.log("Psiphon/Tor routes need hev-socks5-tunnel (remote DNS); not using tun2socks")
            } else if (!Tun2Socks.available) {
                Engine.log("tun2socks library is not in this build, using hev-socks5-tunnel")
            } else if (startTun2Socks(fd, port, s)) {
                return true
            } else {
                Engine.log("tun2socks failed to start, falling back to hev-socks5-tunnel")
            }
        }

        val cfg = File(filesDir, "hev.yml")
        val yml = ArrayList<String>()
        yml += listOf("tunnel:", "  mtu: ${s.mtu()}", "  ipv4: 198.18.0.1")
        if (v6) yml += "  ipv6: 'fc00::1'"
        yml += listOf("socks5:", "  port: $port", "  address: ${LocalHost.host}")
        // Standard SOCKS5 UDP ASSOCIATE for every engine mode except hev-tcp. Leaving this line out
        // is not "no UDP": hev then defaults to its own UDP-over-TCP command (0x05), which Psiphon's
        // SOCKS proxy rejects once per flow, so apps that retry QUIC flood it with refused connections.
        if (s.tunEngine != "hev-tcp") yml += "  udp: 'udp'"
        if (remoteDns) {
            yml += listOf(
                "mapdns:", "  address: 198.18.0.2", "  port: 53", "  network: 100.64.0.0",
                "  netmask: 255.192.0.0", "  cache-size: 10000"
            )
        }
        // Bigger TCP buffer and longer timeouts than hev's defaults (64 KB / 5 s connect), which
        // are too tight for a WARP link. Keys unknown to a given hev version are ignored.
        yml += listOf(
            "misc:", "  tcp-buffer-size: ${s.tcpKb() * 1024}", "  connect-timeout: ${if (s.route.slow) 30000 else 15000}",
            "  tcp-read-write-timeout: 300000", "  udp-read-write-timeout: 60000",
            "  max-session-count: ${if (s.route.slow) 1024 else 0}", "  log-level: warn"
        )
        cfg.writeText(yml.joinToString("\n") + "\n")
        hevOn = try {
            TProxyService.TProxyStartService(cfg.path, fd.fd)
        } catch (e: Throwable) {
            Engine.log("hev-socks5-tunnel failed to start: ${e.message}")
            false
        }
        if (!hevOn) {
            fd.close()
            tun = null
            return false
        }
        startStats()
        return true
    }

    /** Starts sing-box on the TUN that bringUpTun just established. */
    private fun startSingBox(fd: ParcelFileDescriptor, port: Int, s: Settings, v6: Boolean): Boolean {
        val config = SingBox.buildConfig(s, port, v6, tunDnsServers(s).first())
        val err = SingBox.start(this, fd, config) { protect(it) }
        if (err != null) {
            Engine.log("sing-box: $err")
            return false
        }
        sbOn = true
        // sing-box has no byte counters here, so the speed shown (and the "link is alive" check in
        // monitor()) comes from this app's own network counters: the core runs under the same uid.
        startUidStats()
        Engine.log("sing-box (gVisor) running on the TUN")
        return true
    }

    /** IPv4 resolver addresses for the TUN: the user's DNS setting if it has any, else Cloudflare. */
    private fun tunDnsServers(s: Settings): List<String> {
        val custom = s.dns.split(',', ' ', ';', '\n')
            .map { it.trim().removeSuffix(":53") }
            .filter { it.isNotEmpty() && it.all { c -> c.isDigit() || c == '.' } }
        return custom.ifEmpty { listOf("1.1.1.1", "1.0.0.1") }
    }

    /** Hands a dup of the TUN fd to tun2socks (it closes that dup itself on stop). */
    private fun startTun2Socks(fd: ParcelFileDescriptor, port: Int, s: Settings): Boolean {
        val raw = try {
            ParcelFileDescriptor.dup(fd.fileDescriptor).detachFd()
        } catch (e: Exception) {
            Engine.log("tun2socks: could not duplicate the TUN fd: ${e.message}")
            return false
        }
        val rc = try {
            Tun2Socks.start(raw, port, s.mtu(), s.tcpKb())
        } catch (e: Throwable) {
            Engine.log("tun2socks: ${e.message}")
            -9
        }
        if (rc != 0) {
            runCatching { ParcelFileDescriptor.adoptFd(raw).close() }
            Engine.log("tun2socks start failed (code $rc)")
            return false
        }
        t2sOn = true
        // tun2socks has no byte counters, so the speed shown (and the "link is alive" check in
        // monitor()) comes from this app's own network counters: the core runs under the same uid.
        startUidStats()
        Engine.log("tun2socks (Go + gVisor) running on the TUN")
        return true
    }

    private fun startUidStats() {
        statsJob?.cancel()
        statsJob = scope.launch {
            val uid = android.os.Process.myUid()
            var lastTx = android.net.TrafficStats.getUidTxBytes(uid)
            var lastRx = android.net.TrafficStats.getUidRxBytes(uid)
            while (isActive) {
                delay(1000)
                val tx = android.net.TrafficStats.getUidTxBytes(uid)
                val rx = android.net.TrafficStats.getUidRxBytes(uid)
                if (tx >= 0 && rx >= 0 && lastTx >= 0 && lastRx >= 0) {
                    Engine.txBps.value = (tx - lastTx).coerceAtLeast(0)
                    Engine.rxBps.value = (rx - lastRx).coerceAtLeast(0)
                    if (rx > lastRx) lastRxAt = SystemClock.elapsedRealtime()
                } else {
                    Engine.txBps.value = -1
                    Engine.rxBps.value = -1
                }
                lastTx = tx
                lastRx = rx
            }
        }
    }

    /**
     * Reads hev's byte counters once a second (speed display + "link is alive" check) and watches
     * the TUN data path. The ping probes go straight to the local SOCKS port and never touch the
     * TUN, so a healthy core with a stuck TUN engine looks perfect to them. If the apps keep
     * sending for 20 s and not one byte comes back, only hev is restarted (same TUN, same core,
     * same gateway), which clears every stuck session without a slow Psiphon / Tor reconnect.
     */
    private fun startStats() {
        statsJob = scope.launch {
            var lastTx = -1L
            var lastRx = -1L
            var stallSince = 0L
            var stallTicks = 0
            var lastRecycle = 0L
            while (isActive) {
                val st = try { TProxyService.TProxyGetStats() } catch (_: Throwable) { null }
                if (st != null && st.size >= 4) {
                    val now = SystemClock.elapsedRealtime()
                    if (lastTx < 0 || st[1] < lastTx || st[3] < lastRx) {
                        // First sample, or the counters restarted with the engine: new baseline.
                        lastTx = st[1]
                        lastRx = st[3]
                    }
                    val dTx = (st[1] - lastTx).coerceAtLeast(0)
                    val dRx = (st[3] - lastRx).coerceAtLeast(0)
                    Engine.txBps.value = dTx
                    Engine.rxBps.value = dRx
                    if (dRx > 0) {
                        lastRxAt = now
                        stallSince = 0L
                        stallTicks = 0
                    } else if (dTx > 0 && Engine.status.value.phase == Phase.CONNECTED) {
                        if (stallSince == 0L) stallSince = now
                        stallTicks++
                    }
                    lastTx = st[1]
                    lastRx = st[3]
                    if (stallSince != 0L && now - stallSince >= 20_000 && stallTicks >= 8 && now - lastRecycle >= 60_000) {
                        Engine.log("VPN data stall: apps kept sending for ${(now - stallSince) / 1000} s but nothing came back. Restarting the TUN engine (core and gateway stay)")
                        lastRecycle = now
                        stallSince = 0L
                        stallTicks = 0
                        if (recycleHev()) {
                            lastTx = -1L
                            lastRx = -1L
                        }
                    }
                }
                delay(1000)
            }
        }
    }

    /** Stops and restarts hev on the same TUN fd with the same config file. */
    private suspend fun recycleHev(): Boolean = withContext(Dispatchers.IO) {
        synchronized(this@TunnelService) {
            val fd = tun ?: return@synchronized false
            if (!hevOn || stopping) return@synchronized false
            runCatching { TProxyService.TProxyStopService() }
            try { Thread.sleep(300) } catch (_: InterruptedException) { }
            hevOn = try {
                TProxyService.TProxyStartService(File(filesDir, "hev.yml").path, fd.fd)
            } catch (e: Throwable) {
                Engine.log("hev restart failed: ${e.message}")
                false
            }
            hevOn
        }
    }

    // --------------------------------------------------------------- teardown

    private suspend fun teardown() {
        withContext(Dispatchers.IO) { teardownBlocking() }
    }

    /** Stops the TUN engine (tun2socks or hev) and closes the TUN. Safe to call twice. */
    @Synchronized
    private fun stopTunSide() {
        statsJob?.cancel()
        statsJob = null
        if (sbOn) {
            runCatching { SingBox.stop() }
            sbOn = false
        }
        if (t2sOn) {
            runCatching { Tun2Socks.stop() }
            t2sOn = false
        }
        if (hevOn) {
            runCatching { TProxyService.TProxyStopService() }
            hevOn = false
        }
        runCatching { tun?.close() }
        tun = null
    }

    private fun teardownBlocking() {
        runCatching { ShareGateway.stop() }
        unwatchNetwork()
        stopTunSide()
        core?.stop()
        core = null
        wake?.let { if (it.isHeld) it.release() }
        wake = null
        wifi?.let { if (it.isHeld) it.release() }
        wifi = null
    }

    private fun acquireWake(s: Settings) {
        if (!s.keepAwake) return
        val pm = getSystemService(PowerManager::class.java)
        wake = pm.newWakeLock(PowerManager.PARTIAL_WAKE_LOCK, "8vpn:core").apply {
            setReferenceCounted(false)
            acquire()
        }
        // Without this, Wi-Fi may go to power save when the screen is off and the tunnel stalls.
        runCatching {
            val wm = applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager
            @Suppress("DEPRECATION")
            wifi = wm.createWifiLock(WifiManager.WIFI_MODE_FULL_HIGH_PERF, "8vpn:wifi").apply {
                setReferenceCounted(false)
                acquire()
            }
        }
    }

        Phase.CONNECTING -> getString(R.string.connecting)

        Phase.STOPPING -> getString(R.string.stopping)
        Phase.IDLE -> getString(R.string.disconnected)
    }

    private fun notification(text: String): Notification {
        val open = PendingIntent.getActivity(this, 0, Intent(this, MainActivity::class.java), PendingIntent.FLAG_IMMUTABLE)
        val stop = PendingIntent.getService(

        )
        return Notification.Builder(this, CHANNEL)
            .setSmallIcon(R.drawable.ic_stat)
            .setContentTitle(getString(R.string.app_name))

            .setOngoing(true)
            .setContentIntent(open)
            .addAction(
                Notification.Action.Builder(
                    Icon.createWithResource(this, R.drawable.ic_stat), getString(R.string.disconnect), stop

            )
            .build()
    }

    private fun promote() {
        if (foreground) return
        val n = notification(getString(R.string.connecting))

        else startForeground(NOTIF_ID, n)
        foreground = true
    }

package app.vpn8

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import org.json.JSONObject
import java.net.HttpURLConnection
import java.net.URL

/** Only checks the latest GitHub release of 8 VPN. It never downloads or installs anything. */
object Updater {
    private const val API = "https://api.github.com/repos/clubapp8/8vpn/releases/latest"

    data class Info(val tag: String, val newer: Boolean, val url: String)

    suspend fun check(): Result<Info> = withContext(Dispatchers.IO) {
        runCatching {
            val con = (URL(API).openConnection() as HttpURLConnection).apply {
                connectTimeout = 10_000
                readTimeout = 15_000
                setRequestProperty("Accept", "application/vnd.github+json")
                setRequestProperty("User-Agent", "8vpn-android")
            }
            try {
                if (con.responseCode != 200) error("HTTP ${con.responseCode}")
                val j = JSONObject(con.inputStream.bufferedReader().use { it.readText() })
                val tag = j.getString("tag_name")
                val page = j.optString("html_url", "https://github.com/clubapp8/8vpn/releases/latest")
                Info(tag, isNewer(tag, BuildConfig.VERSION_NAME), page)
            } finally {
                con.disconnect()
            }
        }
    }

    private fun parts(v: String) = v.trim().trimStart('v', 'V').split('.', '-', '_')
        .map { p -> p.takeWhile { it.isDigit() }.toIntOrNull() ?: 0 }

    fun isNewer(remote: String, local: String): Boolean {
        val a = parts(remote); val b = parts(local)
        for (i in 0 until maxOf(a.size, b.size)) {
            val x = a.getOrElse(i) { 0 }; val y = b.getOrElse(i) { 0 }
            if (x != y) return x > y
        }
        return false
    }
}

// Package main builds xjasonlyu/tun2socks as an Android shared library (libt2s-jni.so).
//
// Kotlin talks to it through two JNI functions (see jni_shim.c) that take plain ints only:
//
//	start(tunFd, socksPort, mtu) -> 0 on success
//	stop()
//
// The Go runtime lives inside the app process. The TUN fd handed to start() is a dup owned by
// this library: tun2socks closes it on stop().
package main

import "C"

import (
	"fmt"
	"io"
	"sync"
	"time"

	"github.com/xjasonlyu/tun2socks/v2/engine"
	t2slog "github.com/xjasonlyu/tun2socks/v2/log"
	"go.uber.org/zap"
	"go.uber.org/zap/zapcore"
)

var (
	mu      sync.Mutex
	running bool
)

// installNonFatalLogger keeps tun2socks from calling os.Exit(1) (which would kill the whole app)
// if engine.Stop() ever reports an error: a Fatal record becomes a recoverable panic instead.
// The level is clamped to Fatal so the record is not filtered out before the hook runs.
func installNonFatalLogger() {
	core := zapcore.NewCore(
		zapcore.NewConsoleEncoder(zap.NewProductionEncoderConfig()),
		zapcore.AddSync(io.Discard),
		zapcore.FatalLevel,
	)
	t2slog.SetLogger(zap.New(core, zap.OnFatal(zapcore.WriteThenPanic)))
}

//export t2s_start
func t2s_start(fd C.int, port C.int, mtu C.int, bufKb C.int) (rc C.int) {
	mu.Lock()
	defer mu.Unlock()

	if running {
		return -1
	}
	if fd < 0 || port < 1 || port > 65535 {
		return -2
	}
	m := int(mtu)
	if m <= 0 || m > 65535 {
		m = 1500
	}

	kb := int(bufKb)
	if kb < 16 || kb > 4096 {
		kb = 256
	}

	defer func() {
		if r := recover(); r != nil {
			rc = -3
		}
	}()

	engine.Insert(&engine.Key{
		Proxy:      fmt.Sprintf("socks5://127.0.0.1:%d", int(port)),
		Device:     fmt.Sprintf("fd://%d", int(fd)),
		MTU:        m,
		LogLevel:   "silent",
		UDPTimeout: 30 * time.Second,
		// TCP buffers from Settings (default 256 KB, same as the old FCAE build), no auto-tuning.
		TCPSendBufferSize:        fmt.Sprintf("%dk", kb),
		TCPReceiveBufferSize:     fmt.Sprintf("%dk", kb),
		TCPModerateReceiveBuffer: false,
	})
	engine.Start()
	installNonFatalLogger()
	running = true
	return 0
}

//export t2s_stop
func t2s_stop() {
	mu.Lock()
	defer mu.Unlock()
	if !running {
		return
	}
	running = false
	defer func() { _ = recover() }()
	engine.Stop()
}

func main() {}
